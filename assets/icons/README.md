Free icon assets used for popup thumbnails.

- `ball.png`, `crate.png`, `stone_boulder.png`
  - Source: OpenGameArt "Smooth Physics Obstacle Props"
  - Author: Reactorcore
  - License: CC0
  - URL: https://opengameart.org/content/smooth-physics-obstacle-props

Other popup thumbnails are drawn in-app with Flutter Canvas to match the same purpose without text labels.

권리 감사 기록은 [`harness_docs/release/asset_rights_ledger.md`](../../harness_docs/release/asset_rights_ledger.md)에 있으며, 원본 출처 페이지와 CC0 법적 코드의 오프라인 보존본은 `assets/licenses/`에 있다.

`property_shot_app_icon_source.png`는 외부 에셋이 아니라 프로젝트 전용 생성 이미지이며, 앱 아이콘과 런치 화면에만 사용한다. 생성·변환 기록은 [`harness_docs/release/store_assets.md`](../../harness_docs/release/store_assets.md)에 기록한다.
