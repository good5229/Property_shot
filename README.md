# 속성 한방

`속성 한방`은 Flutter와 Flame으로 만든 모바일 캐주얼 퍼즐 게임 프로토타입입니다. 플레이어는 주변 물체의 속성을 공으로 옮기고, 공과 속성을 잃은 원본의 변화를 함께 이용해 한 번의 발사를 설계합니다.

## 프로젝트 의의

- 장르: 속성 조합형 물리 퍼즐·스코어 어택.
- 목표: 상용 전체 서비스가 아니라 핵심 재미를 검증하는 플레이 가능한 수직 프로토타입.
- 핵심 재미: 공의 움직임과 속성을 잃은 원래 물체의 변화를 함께 계산해 연쇄 반응을 성공시키는 만족감.
- 조작 기준: 세로 화면, 한 손 조작, 드래그 조준 후 공을 길게 눌러 자동 발사.

## 현재 구현

- 아홉 개의 테스트 맵.
- 무거움 익히기: 무거움을 가져와 상자를 미는 경로를 익히고, 다른 충돌 경로도 시도한다.
- 탄성 익히기: 탄성을 가져와 첫 반사 방향을 활용하고, 속성 없는 직접 경로도 탐색한다.
- 연쇄 문 열기: 스위치·문·점착판의 상호작용을 익히되, 문을 거치지 않는 경로도 목표로 인정한다.
- 풍선 터뜨리기: 뾰족함을 가져와 풍선을 터뜨리는 경로와 속성 없는 우회 경로를 모두 허용한다.
- 비워진 속성: 무거움·탄성·점착을 공으로 옮기면 원본이 고유 재질 반응을 잃고 움직일 수 있게 되는 양방향 변화를 이용한다. 속성을 옮기지 않는 우회 경로와 두 원본 중 하나를 고르는 배치도 함께 제공한다.
- 속도를 되살리는 길: 공의 감속을 읽고 파워 슬라이더에 진입해 속도를 회복한다. 마지막 구간 재가속, 벽 반사 뒤 진입, 상자를 민 뒤 후속 재가속, 두 발판 선택을 네 패턴으로 제공하며 발판을 쓰지 않는 우회도 허용한다.
- 속성 선택과 공으로 옮기기.
- 속성 선택 후 공으로 복사. 복사는 원래 물체의 속성을 제거하지 않는다.
- 복사는 기본 시작 상태에서 비활성화되며, 3단계 클리어 보상으로 얻은 `복제 코어`를 보유한 경우에만 속성 팝업에 표시된다. 복제 코어는 원본 속성을 유지한 채 공에 복사하고, 사용하면 1개 차감된다. 되감기와 단계 초기화에서는 해당 시점의 코어 수량으로 복원된다.
- 복제 코어 잔여 수량은 A/B `RunState`를 기준으로 획득·소비·되감기·재시작에 걸쳐 저장하며 속성 팝업과 결과 안내에서 한글로 표시한다. 복사하지 않는 물리 경로도 계속 성공할 수 있다.
- 마우스 또는 손가락이 움직이는 방향으로 빨간 발사 화살표 표시.
- 공을 길게 눌러 힘을 모으고, 손을 떼면 자동 발사.
- 조준 후 공 주변에 느린 점멸 링을 표시해 다음 입력 대상을 유도.
- 첫 단계에서는 보드 안에 짧은 코치마크를 순서대로 표시합니다. 바위 선택 뒤 공 충전 안내로 바뀌며, 속성 선택·발사 이후에는 자동으로 사라집니다.
- 아홉 단계의 추천 파는 결정론적 성공 영역 분석에서 산출해 지도·결과 별점에 동기화합니다. 실제 사용자 평균이 아닌 데모 난이도 기준입니다.
- 속성을 가진 물체도 느린 점멸 링으로 선택 가능 여부 표시.
- 물체 탭 시 해당 물체의 속성 또는 역할 설명 표시.
- 벽과 문에 맞으면 공이 튕긴다. 벽은 어떤 경우에도 움직이지 않는다.
- 점착판에 맞은 공은 튕기지 않고 표면에 붙어 멈춘다.
- 공이 스위치를 누르면 스위치가 점멸하고 문이 열리는 애니메이션을 표시한다.
- 움직일 수 있는 물체와 남은 공은 충격을 받아 밀리고, 다른 물체에 운동량을 전달할 수 있다.
- 밀려난 공과 물체도 이동 중 벽, 문, 상자, 돌, 젤리, 점착판, 다른 공과 부딪히면 타입에 맞는 추가 물리 판정을 받는다.
- 밀려난 공은 계산된 중간 충돌 경로를 따라 애니메이션되어 부딪힌 각도와 반사 방향이 화면에 드러난다.
- 공은 처음 빠르게 출발한 뒤 마찰로 점점 느려지고, 충돌 시 추가로 감속된다.
- 무거운 공과 일반 공의 충돌은 질량 차이를 반영해 무거운 공이 진행을 덜 잃고 일반 공을 더 크게 밀어낸다.
- 공이 물체의 어느 면에 맞았는지에 따라 다른 각도로 반사된다.
- 회전 반사판은 8방향 OBB로 충돌하고, 충돌 직전 방향으로 먼저 반사한 뒤 다음 충돌부터 시계 방향 90도 회전한다. 원형 공과 직사각형 이동체는 각각 nearest-point와 SAT 최소 분리축을 사용한다.
- 새로 쏜 공뿐 아니라 이전에 남은 공이 홀에 닿아도 클리어된다.
- 홀에 들어가면 클리어 팝업 표시.
- 클리어 팝업에서 샷 수, 데모용 다른 플레이어 기록, 다음 스테이지 버튼 표시. 마지막 단계에서는 `처음부터 다시`를 표시합니다.
- 클리어 팝업에서 본 목표와 별개인 선택형 `추가 도전`을 표시하고, 1단계 3회 이하·2단계 젤리 충돌·3단계 스위치 작동 달성 여부를 단계별로 로컬 저장합니다. 추가 도전은 성공 조건이 아니므로 여러 풀이 방법을 제한하지 않습니다.
- 위에서 내려다보는 단일 보기.
- 보기 모드에 맞춰 발사 화살표를 표시하되, 충돌 여부와 최종 이동 경로는 숨김.
- 실패한 공의 맵 잔류.
- 공 탭 시 현재 속성과 설명 표시.
- 속성별 색상, 무늬, 공 광택 표시.
- 큐대로 치는 느낌의 발사 연출, 잔상, 충돌 링을 포함한 공 애니메이션.
- UI·속성 선택·속성 이전·복제 코어 획득·조준 충전·발사·가벼운 충돌·무거운 충돌·탄성·점착·젤리·스위치·문·홀·성공·별·메달·실패를 구분하는 사운드 큐. 모바일은 플랫폼 기본 소리, Web은 외부 음원 없이 합성 톤을 사용하며 설정에서 끌 수 있고, 연속 이벤트는 순서대로 재생됩니다.
- 홈 설정에서 효과음·진동·화면 흔들림·저모션 효과를 각각 끌 수 있으며, 설정은 로컬 저장소에 보관됩니다. 저모션에서도 충돌 인과와 홀·상태 변화는 유지됩니다.
- 되감기, 초기화, 일시정지, 샷 수, 점수 표시.

## 설계 원칙

- 게임 판정은 순수 Dart 시뮬레이션에서 결정한다.
- Flame은 확정된 게임 상태를 렌더링하고 애니메이션을 재생한다.
- 같은 초기 상태와 입력은 같은 결과를 낸다.
- 벽은 항상 고정 물체이며, 운동량 전달 대상에서 제외한다.
- 화면 크기와 무관하게 `360 x 560` 논리 좌표계를 유지한다.
- 색상만으로 상태를 구분하지 않고 글자, 무늬, 형태를 함께 사용한다.
- 로그인, 서버, 광고, 결제, 랭킹, 생성형 게임 콘텐츠는 구현하지 않는다.

## 비주얼 방향

- 포코피아 계열의 부드러운 블록 지형을 참고하되, 특정 IP 이미지를 복제하지 않고 자체 Canvas 렌더링으로 표현합니다.
- 잔디 타일 격자, 작은 꽃, 둥근 블록, 말랑한 그림자, 공 얼굴과 볼터치로 귀여운 장난감 필드 느낌을 강화했습니다.
- 공, 상자, 무거운 돌, 홀은 글자 라벨 대신 얼굴, 리본, 돌 형태, 깃발 등 시각 요소로 알아볼 수 있게 했습니다.
- 팝업 썸네일은 글자 대신 무료 아이콘 또는 Canvas 그림 아이콘으로 표시합니다.
- 공 썸네일은 실제 게임 화면의 공 렌더링과 같은 얼굴 달린 구 형태로 표시합니다.
- 상자와 무거운 돌은 팝업과 게임 화면 모두 OpenGameArt의 CC0 `Smooth Physics Obstacle Props` 이미지를 사용합니다.
- 단일 위 보기에서도 공은 구, 상자와 돌은 이미지 기반 물체로 표현합니다.
- 공 발사 중에는 큐대 타격, 잔상, 충돌 링을 표시해 타격감을 강화했습니다.
- 젤리에 맞으면 젤리가 눌렸다가 돌아오는 탄성 애니메이션을 표시합니다.
- 이동 가능한 상자와 돌은 사각형 배경이 아니라 실제 스프라이트를 직접 움직이며, 상자는 기울고 돌은 구르며 충돌 순간에는 형태가 압축됩니다. 공은 구 형태를 유지하고 젤리는 말랑한 몸체로 변형됩니다.
- 현재 리더보드는 서버 없이 데모용 샘플 기록과 내 기록을 함께 보여주는 목업입니다.

## 튜토리얼 검증

- 무거움 익히기: 무거운 공이 상자를 충분히 밀도록 상자 크기와 히트박스, 무거운 공의 밀어내는 힘을 조정했습니다. 무거움은 추천 풀이이며, 다른 물리 경로가 홀에 닿으면 함께 성공합니다.
- 탄성 익히기: 탄성 공의 충돌 결과와 반사 방향은 발사 전에는 숨기고, 실제 충돌 시점부터 화면에 보여줍니다. 반사각은 충돌한 면의 법선을 사용하며, 속성 없는 경로도 성공을 막지 않습니다.
- 연쇄 문 열기: 무거움 속성, 스위치, 문, 점착 표면이 한 맵에 들어 있으며, 각각의 고유 충돌 상호작용을 확인할 수 있습니다. 스위치를 누르면 문이 열리고 점착판은 공을 붙잡지만, 홀은 특정 순서나 기믹 완료를 요구하지 않습니다.
- 비워진 속성: 공이 속성을 얻는 변화와 원본이 속성을 잃고 움직이는 변화를 같은 선택 결과에 표시한다. 네 패턴 모두 원본을 이동시키는 대표 해법과 속성을 옮기지 않는 대체 해법을 결정론적 탐색으로 확인했다.
- 속도를 되살리는 길: 파워 슬라이더가 현재 속도보다 느릴 때만 기준 속도로 올리고, 동일 접촉 반복·무한 가속·고속 터널링을 막는다. 네 패턴에서 대표 성공·약한 발사 성공·슬라이더 미사용 성공을 모두 `ShotResolver`로 탐색하고 고정했다.
- 공은 사라지지 않는다: 첫 공을 쿠션, 스위치 유지 장치, 점착 범퍼, 상자 스토퍼로 남겨 둘째 공과 연결한다. 네 패턴 모두 실제 UI 힘 범위의 대표 두 발 해법과 단일 발사 우회 해법을 함께 제공해 특정 기믹만 강제하지 않는다.
- 세 번 이어라: 3쿠션, 벽·상자·과거 공, 발판·돌·벽·과거 공, 벽·상자·발판·과거 공 연쇄를 네 패턴으로 제공한다. 각 패턴은 1035점 직접 클리어와 1689~2002점 고연쇄 경로가 함께 있어 짧은 성공과 창의적인 고득점을 모두 허용한다. 셔플 백으로 추첨한 패턴과 seed, 여러 번의 속성 행동, 샷 입력 로그를 앱 재시작 뒤 결정론적으로 복원하며 성공 샷 저장 직후 종료해도 런 완료와 지도 기록을 복구한다.
- 판을 돌려 놓아라: 회전 반사판을 한 번 돌린 뒤 다음 샷에 반영하는 경로, 두 반사판 순서, 과거 공의 반사판 작동, 파워 슬라이더 뒤 반사판 연결을 네 패턴으로 제공한다. 모든 패턴은 반사판을 쓰지 않는 직접 우회도 함께 허용하며, 반사판은 충돌 직전 방향으로 먼저 반사한 뒤 다음 충돌부터 90도 회전한다.
- 창의 연쇄 점수: 홀에 들어간 최종 인과 사슬의 깊이, 기물 다양성, 벽 반사, 과거 공, 속성 발동, 슬라이더와 판 상태 변화, 영속 준비 샷을 선택형 고득점으로 분석한다. 반복 접촉·같은 벽면·미세 진동·무관 충돌에는 감쇠와 절대 상한을 적용하며, 기본 클리어 조건과 물리 판정은 바꾸지 않는다. 8단계 클리어 팝업에서 총점과 모든 가산 근거를 한글로 확인할 수 있고 최고 연쇄 점수와 최소 샷 수는 `RunState`에 저장한다.
- 남은 리스크: 아홉 단계가 설명 없이도 직관적인지는 실제 사용자 플레이테스트가 필요합니다. 특히 4단계의 뾰족함·무속성 경로, 5단계의 양방향 변화, 6단계의 발판 진입 각도, 7단계의 과거 공 인과, 8단계의 직접·고연쇄 전략 발견률, 9단계의 반사판 순서·과거 공·슬라이더 경로 발견률은 수동 플레이로 더 검증해야 합니다.
