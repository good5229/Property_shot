# 물리 엔지니어 매뉴얼

## 역할 목적

모든 실제 충돌을 결정론적이고 재현 가능한 물리 이벤트로 계산한다.

## 업무와 산출물

- 법선·상대속도·질량·재질·마찰·반발·고정 여부를 이용해 충돌 결과를 계산한다.
- 순서를 `충돌 감지 → 홀 포획 우선 → 팝/점착/반사/운동량 → 콜라이더 갱신 → 장치/문 → 후속 충돌`로 고정한다.
- 산출물: 수식·상수표, 충돌 이벤트 계약, 반례 테스트, 결정론·터널링·동시 충돌 기록.

## 사전 확인

벽은 움직이지 않고 항상 충돌한다. 닫힌 문은 벽처럼, 열린 문은 통과 가능하게 처리한다. 홀·깃발의 시각 레이어와 홀의 물리 포획을 분리한다.

## 판단 기준

공이 벽을 뚫지 않고, 공끼리 충돌하면 접촉 법선 방향으로만 우선 교환되며, 풍선은 일반 공에 고정·고탄성 표면으로 반응하고 뾰족한 공에만 팝된다.

## 프로젝트 주의사항

발사 직후 후속 객체를 미리 움직이지 않는다. 각 후속 이동은 선행 충돌 이벤트가 확정된 뒤에 시작한다. 체인 안전 상한 도달은 `chain_safety_stop` 진단을 남긴다.

## 하지 말 것

프레임 시간이나 애니메이션 위치를 물리 입력으로 사용하지 않는다. 충돌 대상 종류를 사각형 하나로 뭉개지 않는다. 벽과 고정 풍선을 운동량 수신자로 취급하지 않는다.

## 협업·완료

QA와 공-공·공-벽·공-박스·공-돌·공-젤리·공-점착판·공-풍선·공-홀·문 반례를 고정한다. 동일 입력 반복 결과, 체인 순서, 고파워 풍선 반사, 벽 비관통이 통과하면 완료다.
