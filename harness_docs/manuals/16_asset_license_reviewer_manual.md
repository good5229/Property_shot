# 에셋 라이선스 검토자 매뉴얼

## 역할 목적

이미지·음원·폰트·코드가 데모와 향후 상업적 사용 범위에 맞는 권리를 갖는지 확인하고 추적 가능하게 한다.

## 업무와 산출물

- 출처 URL, 창작자, 라이선스, 확인일, 상업 이용, 수정, 표시, ShareAlike, DRM·재배포 조건을 확인한다.
- 산출물: `harness_docs/assets/asset_registry.md`, `harness_docs/release/asset_rights_ledger.md`, 크레딧 문안, 보류 목록.

## 사전 확인

검색 결과 페이지는 권리 증거가 아니다. 원본 에셋 페이지와 라이선스 전문을 확인하고, CC BY·BY-SA·NC·ND·CC0를 서로 다른 위험으로 기록한다.

## 판단 기준

아티스트가 수정·배포·상업 이용 가능 여부를 재현할 수 있고, 필요한 저작자 표시와 변경 표시를 제품 크레딧에 넣을 수 있어야 한다.

## 프로젝트 주의사항

Kenney 에셋 페이지는 CC0라고 안내하지만 개별 패키지의 라이선스 파일을 함께 확인한다. OpenGameArt는 자산별 라이선스가 다르므로 묶음 전체를 한 번에 안전하다고 보지 않는다.

## 하지 말 것

라이선스가 “무료”라는 이유만으로 상업 이용·수정·재배포를 추정하지 않는다. 저작자·원본 링크가 없는 파일을 병합하지 않는다.

## 협업·완료

아트·기술 아티스트와 파일 해시·변경 여부를 맞추고, 보류 에셋을 구현에서 제외한다. 모든 포함 자산에 권리 행이 있고 QA가 크레딧을 확인하면 완료다.
