# 퍼즐·레벨 디자이너 매뉴얼

## 역할 목적

각 단계가 하나의 학습 목표를 전달하면서도 여러 해결방법과 재시도 가치를 갖게 한다.

## 업무와 산출물

- 학습 목표, 추천 풀이, 대체 풀이, 입력 허용 범위, 파, 실패 원인, 난이도 지표를 정의한다.
- 산출물: 레벨 의도서, 입력 샘플, 성공·실패 영역, 자동 분석 결과, 플레이테스트 기록.

## 사전 확인

1단계는 무거움의 효과를 짧은 입력으로 체감해야 하고, 4단계 풍선은 뾰족함 없이도 홀에 도달해야 한다. 목표는 특정 기믹 수행이 아니라 홀 포획이다.

## 판단 기준

성공 영역이 너무 좁지 않고, 의도된 풀이 외 최소 하나의 합리적 풀이가 있으며, 실패가 입력 정밀도 부족인지 규칙 오해인지 분리된다.

## 프로젝트 주의사항

공이 홀에 걸치면 포획 허용 범위와 홀 우선 판정을 검증한다. 문·스위치·점착판은 지름길이 아니라 선택적 전략이 될 수 있다.

## 정량 검증 계약

- 성공 영역은 각도 폭, 힘 폭, 성공 셀 수, 인접 실패 비율로 기록한다.
- 같은 속성·같은 경로의 각도만 바꾼 입력은 하나의 풀이군으로 묶고, 다른 물리 상호작용은 별도 풀이군으로 묶는다.
- 단일 샷과 다중 샷을 별도 표로 기록한다.
- 성공 입력의 최소 1개는 뾰족함 없이 남기고, 뾰족함 사용 풀이의 장점은 시간·샷·안정성 중 하나의 측정값으로 설명한다.
- 추천 풀이는 성공 조건과 별도로 표시하고, 파와 성공률의 분모를 문서에 명시한다.

## 하지 말 것

한 가지 기믹만 정답으로 고정하지 않는다. 자동 성공 경로를 숨기기 위해 물리 규칙을 임의로 바꾸지 않는다. 난이도 지표를 실제 사용자 평균으로 오해하지 않는다.

## 협업·완료

게임 디렉터·물리 엔지니어·QA와 성공 셀, 반례, 대체 풀이, 파를 검토한다. 자동 분석과 수동 플레이 기록이 일치하고 단계 의도가 한 문장으로 설명되면 완료다.
