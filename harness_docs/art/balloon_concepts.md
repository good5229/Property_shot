# 풍선 시안 기록

## 공통 평가 항목

탑뷰 실루엣, 부피감, 기존 바위·상자와의 광원, 끈·매듭 가독성, 눌림·팝 상태, 일반 충돌과 뾰족함 팝의 구분을 0~5점으로 평가한다.

| 시안 | 설명 | 장점 | 위험 | 판정 |
|---|---|---|---|---|
| A Canvas 둥근 풍선 | 단순 원형·끈·하이라이트 | 상태 전환과 성능이 명확 | 재질감이 약함 | 보류 |
| B Canvas 풍선 | 원형 본체·하이라이트·끈·눌림·팝 조각 | 상태와 충돌 역할을 가장 빠르게 읽음 | 래스터와 광원 비교 필요 | 채택 |
| C 외부 래스터 | 귀여운 풍선 스프라이트 | 질감이 풍부함 | 권리·상태별 에셋 비용 | 미채택 |

현재 구현은 `balloon-canvas`이며 `기본 → 눌림 → 반사 또는 팝 → 비활성` 상태를 렌더링한다. 판정은 [풍선 기믹 명세](../design/balloon_mechanic_spec.md)를 따른다.
