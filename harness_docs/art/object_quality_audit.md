# 오브젝트 시각 품질 감사 기준

## 공통 체크

- `390×844`, `393×852`, `430×932`, `768×1024`, `1024×1366`에서 공·박스·돌·젤리·풍선·가시·문·홀·깃발을 실루엣으로 구분할 수 있는가.
- 움직일 때 사각형 디버그 박스가 아니라 실제 형태가 이동·기울기·압축되는가.
- 충돌 전·접촉·후속 이동·정지 상태가 한 프레임 이상 구분되는가.
- 속성은 색상 외 무늬·형태·문구로도 확인되는가.
- 홀의 깃발과 내부 깊이가 목표를 표시하지만 물리 콜라이더를 대신하지 않는가.
- 회색조와 색상 제거 상태에서도 물체 종류와 상태를 구분할 수 있는가.
- 외곽선과 내부 무늬가 작은 화면에서 뭉개지지 않는가.

## 앵커·히트박스

- 표시 피벗과 판정 중심의 오프셋을 자산별로 기록한다.
- 그림자와 장식은 충돌 외곽에 포함하지 않는다.
- 풍선 팝 프레임은 충돌 후보 제거 이후에 표시한다.

## 합격 조건

아트 디렉터·기술 아티스트·QA가 같은 캡처를 보고 물체·상태·목표·충돌 결과를 일치하게 설명하고, 권리 대장에 자산 출처가 연결되어야 한다.
