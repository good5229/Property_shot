# 대표 보드 구성

## 화면 층

1. 바깥 배경: 따뜻한 종이·목재색으로 게임판과 화면을 분리한다.
2. 목재 프레임: 플레이 영역의 경계를 두껍고 둥근 장난감 구조물로 보여 준다.
3. 플레이 필드: 밝은 잔디와 얕은 재질 변화만 사용하고 조작 경로는 비워 둔다.
4. 게임 오브젝트: 공·홀·상자·속성 공급원·장애물의 실루엣을 가장 높은 대비로 표현한다.
5. HUD: 게임판 위에 겹치지 않는 상단·하단 정보 영역으로 유지한다.

## 1단계 시선 흐름

`무거운 돌 → 공 → 상자 → 홀`

- 무거운 돌은 청회색 속성 링으로 선택 가능 상태를 알린다.
- 공과 상자 사이에는 장식을 두지 않아 충돌 경로를 읽기 쉽게 한다.
- 상자는 중앙의 대표 이동 물체로 유지한다.
- 홀은 노랑 목표 링과 산호색 깃발로 첫 화면에서 즉시 찾게 한다.

## 장식 규칙

- 장식은 모서리와 빈 공간에만 둔다.
- 공·상자·홀·벽의 히트박스를 가리지 않는다.
- 장식은 물리 오브젝트와 같은 외곽선 규칙을 사용하지 않아 구분한다.
- 작은 화면에서는 장식 수를 줄이고 목표와 조작 대상 대비를 우선한다.
