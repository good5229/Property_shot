# 입력별 대리 플레이테스트 문구 v2

공통 제한: 공개 화면과 접근성 트리만 사용한다. 저장소, 소스 코드, 시나리오 ID, 정답 각도·힘, 테스트 fixture를 보지 않는다. 재미를 점수화하지 않고 입력 장벽과 오류만 기록한다.

## mobile_touch

320×568 세로 화면에서 손가락 하나의 포인터 입력만 사용하세요. 첫 화면에서 실험 목표와 시작 행동을 말한 뒤, 화면을 가리는 요소 없이 속성을 선택하고 조준해 최대 5회 발사하세요. 각 단계에서 버튼이 잘렸는지, 잘못 눌렀는지, 보드와 하단 조작부가 겹쳤는지를 기록하세요. 키보드와 의미 custom action은 사용하지 마세요.

## keyboard_only

390×844 화면에서 Tab, Shift+Tab, 방향키, +/-, Space, Esc만 사용하세요. 현재 포커스가 눈에 보이는지 먼저 확인하고, 보드에 포커스를 둔 뒤 조준·힘 조절·발사를 수행하세요. 반복 Space나 길게 누른 Space도 한 번만 발사되는지, 팝업 안에서 Tab이 빠져나가지 않는지, Esc가 저장된 결과를 버리지 않는지 기록하세요. 포인터 입력은 사용하지 마세요.

## semantics_only

스크린샷의 픽셀 정보는 사용하지 말고 의미 라벨, value, live region, increase/decrease, custom action만 사용하세요. 화면 이름, 실험 목표, 현재 조준 상태, 가능한 다음 행동을 자신의 말로 설명한 뒤 실험을 진행하세요. 색·위치·아이콘만으로 추측하지 말고, 상태 변화가 의미 정보로 전달되지 않으면 blocked로 기록하세요.

## abnormal_input

정답을 찾는 대신 경계 입력의 안전성을 확인하세요. 빈 공유 코드, 최대 길이 초과 코드, 변조된 코드, 빠른 두 번 탭, 반복 Space, 애니메이션 중 reset, 팝업 뒤 방향키, 저장 중 나가기를 각각 한 번만 시도하세요. crash, 중복 발사, 중복 보상, 캠페인 진행 변경이 없어야 합니다. 입력이 무시되거나 안전한 한글 오류 뒤 복구되면 정상으로 기록하세요.
