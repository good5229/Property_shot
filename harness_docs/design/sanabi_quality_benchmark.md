# 《산나비》 완성도 벤치마크와 속성 한방 보완 방향

## 판단 전제

《산나비》를 규모나 장르의 복제 대상으로 삼지 않는다. 5명이 약 4년간 개발한 PC·콘솔 상용작과 현재의 모바일·웹 물리 퍼즐을 콘텐츠 분량으로 직접 비교하면 실행 가능한 결론이 나오지 않는다. 대신 심사자가 짧은 시간 안에 체감하는 `기억되는 한 문장`, `일관된 세계`, `조작과 연출의 결합`, `플레이할 감정적 이유`, `마감 품질`을 비교한다.

공개 자료에서 확인되는 《산나비》의 강점은 다음과 같다.

- 사슬팔 하나로 이동·전투·레벨 통과를 묶은 즉시 설명 가능한 핵심 동사
- 조선 건축과 한국어 간판을 사이버펑크에 결합한 고유한 세계 실루엣
- 복수로 시작해 인간성에 대한 메시지로 이어지는 감정적 진행 동력
- 픽셀 아트, 비, 조명, 신스웨이브 음악, 속도감 있는 이동이 같은 분위기를 강화하는 시청각 일관성
- 데모와 베타 피드백을 거쳐 반복적 구간을 덜어내고 게임패드 조작을 개선한 출시 전 다듬기

## 이번에 반영한 보완

1. 홈과 섬 지도에 하나의 원경을 공유하는 `island-restoration-world-v1.webp`를 적용했다. 관측소·등대·다리가 장기 목표로 동시에 보인다.
2. 홈 설명을 조작 설명만이 아니라 “물리 규칙을 발견해 멈춘 시설을 깨운다”는 플레이 이유로 바꿨다.
3. 기존 UI 카드에는 반투명 표면을 유지해 배경이 세계를 만들되 정보 대비를 해치지 않게 했다.
4. 생성 자산의 프롬프트·권리 검토·SHA-256을 권리 원장과 번들 계약에 기록했다.
5. 강한 충돌에 8프레임 이내의 짧은 카메라 펀치를 적용하고, 무거움·탄성·점착·뾰족함을 파편 형태와 색으로 구분했다. 모션 감소에서는 확대를 끄고 파티클 수를 줄인다.
6. Canvas 기물과 공에 공통 짙은 실루엣, 왼쪽 위 림라이트, 하단 음영을 적용해 스위치·문·반사판·공도 같은 재질 규칙으로 읽히게 했다.

## 다음 품질 게이트

### P0 — 심사 시연 전에 필요

- 시설 복구 순간의 빛이 홈·지도 배경의 해당 시설로 이어지도록 장면 전환을 보강한다. 발사 충돌 카메라 펀치와 속성별 파티클은 이번 렌더 패스에서 반영했다.
- 첫 3단계에서 각 단계가 하나의 “장면”으로 끝나도록 성공 직후 인과 한 줄과 시설 변화 한 컷을 연결한다.
- 풍선의 천 재질과 문 개방 전후의 발광 상태를 한 단계 더 세분화한다. 공통 재질·광원·외곽선 패스는 이번 렌더 개선에서 반영했다.

### P1 — 입상권을 노리는 차별화

- 말이 많은 스토리 대신 관측소 관리자 또는 기록 장치 하나를 도입해, 발견 전 질문과 발견 후 의미를 1문장씩 전달한다.
- 10단계를 단순 규칙 목록이 아니라 `시설을 켠다 → 항로를 밝힌다 → 다리를 잇는다`의 세 막으로 재배열한다.
- 속성마다 음악 레이어와 충돌 음색을 달리하고, 연쇄가 깊어질수록 같은 테마가 풍성해지는 적응형 사운드를 만든다.

### P2 — 상용 완성도

- 다양한 초행 플레이 영상으로 입력 시간·실패 이유·재시도 의향을 관찰한다. 자동 테스트는 재미를 대신하지 않는다.
- 60fps 실기기 프레임, 오디오 지연, 햅틱 강도, 브라우저 메모리를 별도 성능 예산으로 관리한다.
- 제목 화면, 스테이지 카드, 게임판, 결과 화면의 아이콘·그림자·라운드 값에 공통 디자인 토큰을 적용한다.
