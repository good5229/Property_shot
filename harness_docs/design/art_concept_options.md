# 해변 실험 섬 아트 콘셉트 비교

세 시안은 같은 물리 퍼즐 세계 안에서 비교했다. 특정 게임의 캐릭터나 UI를 복제하지 않는다.

| 시안 | 환경 | 장점 | 위험 | 적용 상태 |
| --- | --- | --- | --- | --- |
| A. 햇빛 정원 보드 | 잔디, 목재, 꽃, 관목 | 따뜻하고 교육적인 첫 인상 | 현재 민트 보드와 차별이 약함 | 보조안 |
| B. 해변 실험 섬 | 모래, 얕은 물, 조개, 야자 잎, 산호 장치 | 사용자 선호와 공·홀의 캐주얼성이 잘 맞음 | 모래와 상자의 갈색이 섞일 수 있음 | **기본 채택** |
| C. 구름 위 장난감 공방 | 목재 플랫폼, 로프, 금속 장치, 하늘 | 속성 장치를 발명품처럼 설명하기 좋음 | 물리 판정 면과 장식 구조가 복잡해짐 | 후속 후보 |

## 화면별 비교 기준

| 화면 | A | B | C |
| --- | --- | --- | --- |
| 홈 | 정원 표지판과 공 | 모래섬 위 공과 물결 | 공방 표지판과 도구 |
| 스테이지 선택 | 꽃길 경로 | 조개·깃발 섬 경로 | 부품이 이어진 작업대 |
| 플레이 | 잔디판과 목재 테두리 | 모래판과 청록 섬 벽 | 플랫폼과 로프 경계 |
| 결과 | 꽃잎·별 | 깃발·조개·별 | 톱니·빛·별 |

## 선정 근거

- 사용자는 포코피아 계열의 밝고 귀여운 지형 감성을 선호한다고 밝혔고, 해변·섬 방향을 우선 검토하도록 지정했다.
- B는 공·홀·벽을 한 장소 안에 자연스럽게 묶으면서 현재 고품질 돌·상자 에셋을 모래 바닥에 배치하기 쉽다.
- B를 구현하되 특정 IP의 야자수, UI, 캐릭터, 스테이지 구조는 사용하지 않는다.

## 품질 게이트

- 홈과 플레이 보드의 배경 색·광원 방향이 일치해야 한다.
- 벽·문·스위치·점착판이 래스터 상자·돌·젤리와 같은 재질 규칙을 가져야 한다.
- 장식이 공·홀·충돌면을 가리지 않아야 한다.
- 스크린샷에서 게임 보드가 단색 민트 개발 화면으로 보이지 않아야 한다.
