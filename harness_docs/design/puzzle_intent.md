# 퍼즐 의도표

| 레벨 | 학습 목표 | 의도된 풀이 | 대체 풀이·위험 |
|---|---|---|---|
| 무거움 익히기 | 질량과 상자 이동 | 무거움을 공에 옮겨 상자를 밀고 홀로 향하는 경로를 익힌다 | 일반 공의 직접 조준, 상자 옆 통과, 다른 충돌 순서도 홀 진입 시 성공 |
| 탄성 익히기 | 충돌면 반사와 에너지 보존 | 탄성을 공에 옮겨 벽의 면을 비스듬히 맞혀 홀 방향을 만든다 | 속성 없는 직선·벽·가장자리 경로도 물리적으로 홀에 닿으면 성공 |
| 연쇄 문 열기 | 점착·스위치·문 | 점착판과 무거운 스위치의 상호작용을 조합해 열린 문을 통과하는 경로를 익힌다 | 점착판 없이 스위치를 누르거나, 문을 피해 홀로 가는 경로도 허용 |
