# 퍼즐 의도표

| 레벨 | 학습 목표 | 의도된 풀이 | 대체 풀이·위험 |
|---|---|---|---|
| 무거움 익히기 | 질량과 상자 이동 | 무거움을 공에 옮겨 상자를 밀고 홀로 향함 | 힘이 충분하면 일반 공으로도 풀리는지 수동 확인 |
| 탄성 익히기 | 충돌면 반사와 에너지 보존 | 탄성을 공에 옮겨 벽의 면을 비스듬히 맞혀 홀 방향을 만든다 | 일반 공은 같은 반사각을 만들 수 있지만 충돌 에너지 부족으로 홀에 도달하지 못해야 함 |
| 연쇄 문 열기 | 점착·스위치·문 | 점착판에 공을 붙여 발판을 만든 뒤, 무거운 공으로 스위치를 눌러 열린 문을 통과한다 | 점착 발판이 없으면 스위치가 열리지 않으며, 일반 공의 스위치 우회도 허용하지 않는다 |
