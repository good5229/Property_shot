# 오브젝트 스타일 가이드

## 공통 규칙

- 모든 물체는 왼쪽 위 광원, 접지 그림자, 따뜻한 외곽선, 얕은 2.5D 깊이를 공유한다.
- 색상만으로 속성을 구분하지 않고 아이콘·무늬·형태를 함께 사용한다.
- 이동 물체는 이미지 또는 실제 형태 변형으로 움직이며 사각형 디버그 박스를 노출하지 않는다.
- 장식은 충돌하지 않고, 충돌 물체는 명확한 실루엣과 상태 변화를 가진다.

## 현재 적용

상자·돌·젤리는 이미지와 변형 애니메이션을 사용한다. 벽·문·스위치·점착판·홀은 Canvas 도형이지만 동일한 광원·그림자·외곽선 규칙으로 그린다. 래스터와 Canvas의 질감 통일은 실제 픽셀 골든과 실기기에서 추가 확인한다.
