# 복사권 설계

## 채택안

현재 제품 데모는 모델 B인 `조건부 복제 코어`를 사용한다.

| 상태 | 복사 가능 여부 | 복원 시점 |
| --- | --- | --- |
| 첫 챕터 시작 | 불가 | 해당 없음 |
| 3단계 클리어 보상 획득 후 | 복제 코어 보유 수만큼 가능 | 되감기·단계 초기화에서 해당 상태 복원 |

복사는 원본 속성을 유지한 채 현재 공에 속성을 부여한다. 복제 코어를 실제로 적용하는 순간 코어 1개를 소모하며, 속성 선택 실패나 코어 소진 상태에서는 상태를 변경하지 않는다.

## 플레이 원칙

- 복사는 클리어의 필수 조건이 아니다.
- 이전 기능과 속성 없는 공의 물리 경로를 포함한 여러 해결방법을 유지한다.
- 잔여 복제 코어는 속성 팝업과 결과 안내에 한글로 표시한다.
- 코어가 없으면 복사 버튼 자체를 노출하지 않아 이전과 복사의 차이를 혼동시키지 않는다.
- 복제 코어는 로컬 진행 상태로만 저장하고, 상점·과금·온라인 공유는 추가하지 않는다.

## 검증

`flutter test` 기준 최신 테스트에서 복사 성공, 원본 유지, 소진, 실패 선택 무차감, 되감기 복원, 첫 시작 숨김, 코어 보유 시 위젯 표시를 검증한다.
