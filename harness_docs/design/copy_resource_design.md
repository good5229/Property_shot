# 복사권 설계

## 채택안

현재 데모는 모델 A인 `스테이지당 제한 복제권`을 사용한다.

| 단계 | 복사권 | 복원 시점 |
| --- | ---: | --- |
| 1단계 | 1회 | 되감기·단계 초기화 |
| 2단계 | 1회 | 되감기·단계 초기화 |
| 3단계 | 2회 | 되감기·단계 초기화 |

복사는 원본 속성을 유지한 채 현재 공에 속성을 부여한다. 성공한 복사만 복사권을 1회 소모하며, 속성 선택 실패나 복사권 소진 상태에서는 상태를 변경하지 않는다.

## 플레이 원칙

- 복사는 클리어의 필수 조건이 아니다.
- 이전 기능과 속성 없는 공의 물리 경로를 포함한 여러 해결방법을 유지한다.
- 잔여 복사권은 속성 팝업과 결과 안내에 한글로 표시한다.
- 소진된 복사 버튼은 비활성화해 현재 상태를 예측할 수 있게 한다.
- 복사권은 세션 간 공유 재화가 아니며, 현재 수직 데모의 범위를 벗어난 저장·상점·과금 시스템은 추가하지 않는다.

## 검증

`flutter test` 기준 105개 테스트에서 복사 성공, 원본 유지, 소진, 실패 선택 무차감, 되감기 복원, 단계별 수량, 위젯 표시를 검증한다.
