# 피드백과 타격감

## 이벤트 순서

충돌 접점 강조 → 대상의 압축·흔들림 → 운동량 전달 → 반사·정지 → 다음 연쇄 이벤트 순으로 재생한다. 논리 결과는 순수 Dart가 결정하고 Flame은 `ShotImpact`와 이동 경로를 재생한다.

## 재질별 표현

- 무거움: 낮고 넓은 충돌 링과 강한 흔들림
- 탄성: 밝은 링과 빠른 반발
- 점착: 눌림 뒤 정지와 부착 표시
- 젤리: 압축·복원과 작은 물방울
- 홀: 중심 흡입과 축소·페이드

현재 Canvas 연출과 기본 플랫폼 사운드·햅틱 연결은 자동 테스트로 확인했다. 실제 기기의 프레임·햅틱 강도·사운드 만족도는 미검증이다.
