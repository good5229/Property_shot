# 피드백과 타격감

## 이벤트 순서

충돌 접점 강조 → 대상의 압축·흔들림 → 운동량 전달 → 반사·정지 → 다음 연쇄 이벤트 순으로 재생한다. 논리 결과는 순수 Dart가 결정하고 Flame은 `ShotImpact`와 이동 경로를 재생한다.

## 재질별 표현

- 무거움: 낮고 넓은 충돌 링과 강한 흔들림
- 탄성: 밝은 링과 빠른 반발
- 점착: 눌림 뒤 정지와 부착 표시
- 젤리: 압축·복원과 작은 물방울
- 홀: 중심 흡입과 축소·페이드

강한 충돌은 접점 기준으로 짧은 카메라 펀치를 적용한다. 물리 좌표와 히트박스는 움직이지 않고 Canvas 변환만 사용하며, 8프레임 안에 원래 배율로 복귀한다. 속성 파티클은 무거움의 각진 파편, 탄성의 민트 물방울·파동, 점착의 늘어진 방울, 뾰족함의 짧은 선광으로 구분한다. 홀 진입은 바깥에서 중심으로 모이는 광선으로 종결을 읽게 한다.

모든 Canvas 기물은 왼쪽 위 림라이트, 짙은 청록 실루엣, 하단 음영을 공유한다. 이 처리는 렌더 계층에만 있으며 ShotResolver 결과와 replay fingerprint에는 영향을 주지 않는다. 모션 감소에서는 카메라 확대를 끄고 파티클 수를 줄여 정적인 상태 변화가 우선 보이게 한다.

현재 Canvas 연출과 기본 플랫폼 사운드·햅틱 연결은 자동 테스트로 확인했다. 실제 기기의 프레임·햅틱 강도·사운드 만족도는 미검증이다.
