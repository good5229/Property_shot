# 온보딩 흐름

## 첫 진입

1. 목표 홀과 공을 먼저 찾는다.
2. 속성 물체를 누르면 정보 팝업에서 이전 또는 복사를 선택한다.
3. 방향을 움직이고 공을 0.45초 이상 누른 뒤 손을 뗀다.
4. 충돌 결과를 관찰하고 실패하면 힘·각도·속성을 바꿔 재시도한다.

넓은 화면과 축약 화면 모두 같은 순서를 보여줘야 한다. 320px 축약 HUD에는 `1 방향 조정 · 2 공을 길게 누르기 · 3 손 떼기`를 표시하며 위젯 테스트로 존재를 고정한다.

## 원칙

예상 최종 궤적을 보여주지 않고, 특정 기믹을 정답으로 강제하지 않는다. 실패 안내는 다음 실험의 방향을 제시하되 정답 경로를 확정하지 않는다.
