# 속성 한방 비주얼 스타일 바이블

## 결정

기본 테마는 `B. 해변 실험 섬`이다. 밝은 모래섬 위에 장난감 물리 실험 보드가 놓인 세계를 만든다. 바위와 상자는 기존 래스터 에셋을 유지하고, 나머지 요소를 같은 광원·접지·외곽선·재질 규칙으로 맞춘다.

## 세계관 규칙

- 플레이 보드는 하나의 작은 섬 실험장이다.
- 장식은 모래, 얕은 물, 조개, 야자 잎, 표지판으로 제한한다.
- 장식은 충돌 물체보다 채도를 낮추고 입력 대상이 아니다.
- 화면은 단일 탑뷰이며 회전·입체 회전 기능을 사용하지 않는다.
- 환경 장식이 퍼즐 물체의 실루엣을 가리지 않는다.

## 공통 광원과 형태

- 주광은 왼쪽 위에서 오른쪽 아래로 향한다.
- 모든 이동 물체는 접지 그림자와 짧은 하단 압출면을 가진다.
- 외곽선은 짙은 청록 계열, 기본 1.5~2.5 논리 픽셀이다.
- 충돌 가능한 실루엣은 장식보다 명확한 대비를 가진다.
- 상자와 돌은 흰색 빗금을 사용하지 않는다.
- 애니메이션은 물리 이벤트 뒤에 시작하며 물리 상태를 바꾸지 않는다.

## 물체별 재질

| 물체 | 실루엣·재질 | 충돌 피드백 |
| --- | --- | --- |
| 공 | 둥근 플라스틱, 얼굴, 볼터치, 속성별 표면 무늬 | 압축 → 발사 신장 → 충돌 링 |
| 상자 | 따뜻한 나무결, 넓은 면, 짧은 압출면 | 이동 방향 흔들림, 낮은 충돌음 |
| 무거운 돌 | 청회색의 둥근 돌, 낮은 중심, 면 하이라이트 | 먼지·짧은 묵직한 반동 |
| 젤리 | 청록 반투명 고무, 둥근 반사 패치 | 충돌면 압축·복원·물방울 |
| 점착판 | 보라색 끈기 표면, 작은 방울과 부착 링 | 눌림·늘어짐·정지 |
| 벽 | 섬 테두리 또는 청록 장난감 레일 | 고정된 접촉면, 반사 링 |
| 문 | 산호색 장난감 성문, 경첩과 잠금 표시 | 스위치 신호 전달 후 열림 |
| 스위치 | 문과 같은 문양의 섬 장치 | 점멸·눌림·문까지 신호 |
| 홀 | 잔디 링, 함몰, 천 깃발 | 흡입·축소·성공 파티클 |

## 속성의 비색상 구분

- 무거움: 낮은 실루엣, 돌 질감, 무게 중심 표시.
- 탄성: 두 겹의 둥근 고리, 반사 하이라이트.
- 점착: 방울 점무늬, 표면에 붙는 작은 링.
- 색약 환경에서는 패턴과 아이콘이 색상보다 우선한다.

## 화면 위계

- 보드가 첫 번째, 공과 홀은 두 번째, 목표·힘 HUD는 세 번째다.
- 긴 설명은 플레이 보드 밖에 두지 않는다.
- 한 번에 하나의 행동 안내만 표시한다.
- 결과 화면의 주요 행동은 `다음`, `기록 다시 도전`, `섬 지도` 순서다.
- 모바일 Safe Area와 최소 44 논리 픽셀 터치 영역을 지킨다.

## 금지 규칙

- 개발용 단계 칩을 실제 플레이 화면에 노출하지 않는다.
- 검은 최종 궤적 실선을 표시하지 않는다.
- 회전 뷰·쿼터뷰·사용자 카메라 회전을 다시 추가하지 않는다.
- 특정 상용 게임의 캐릭터, 아이콘, 배치, 색상 조합, 스테이지를 복제하지 않는다.
