# 속성 한방 시각 스타일 가이드

## 방향

밝은 장난감 정원 위의 물리 퍼즐 보드. 특정 게임의 캐릭터·UI·레벨·에셋을 복제하지 않고, 따뜻한 목재 프레임과 풀이 섞인 자체적인 작은 디오라마 세계를 만든다.

## 공통 규칙

- 광원은 왼쪽 위에서 고정한다.
- 모든 오브젝트는 짙은 청록 외곽선과 접지 그림자를 가진다.
- 2.5D 압출 방향은 화면 전체에서 동일하게 유지한다.
- 선택 가능 상태는 속성 색상의 느린 링 하나로 표현한다.
- 충돌 상태는 접촉면 방향의 짧은 빛, 스쿼시, 링으로 표현한다.
- 색상만으로 속성을 전달하지 않고 실루엣·무늬·아이콘을 함께 사용한다.
- 게임판 장식은 물리 판정과 입력 영역에 참여하지 않는다.

## 재질

| 요소 | 표현 |
|---|---|
| 공 | 반사광이 있는 둥근 플라스틱, 얼굴과 볼터치 |
| 상자 | 따뜻한 나무, 낮은 광택, 큰 나무결 |
| 돌 | 거친 청회색 표면, 넓은 면 변화, 흰색 빗금 없음 |
| 젤리 | 반투명 청록, 둥근 반사 패치, 눌림과 복원 |
| 점착판 | 보라색 끈기 표면, 작은 방울과 고정 링 |
| 벽 | 무광 청록 고무 또는 장난감 레일 |
| 문 | 산호색 장난감 성문, 경첩과 잠금 장치 |
| 홀 | 잔디 링과 어두운 함몰, 천 깃발 |
| UI | 종이 또는 장난감 플라스틱 패널, 짧은 한글 문장 |

## 속성 색상

- 무거움: 청회색
- 탄성: 청록
- 점착: 보라
- 성공·열림: 밝은 초록
- 경고·실패: 산호색
- 목표: 노랑

속성 색상과 상태 색상이 겹칠 때는 무늬와 아이콘을 우선해 구분한다.
