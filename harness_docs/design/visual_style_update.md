# 시각 스타일 갱신

## 원칙

- 단일 탑뷰와 귀여운 물리 장난감 분위기를 유지한다.
- 공은 얼굴이 있는 원형, 상자·돌은 실제 형태가 보이는 래스터 또는 Canvas 물체로 그린다.
- 광원 방향, 외곽선, 접지 그림자, 재질 무늬를 오브젝트 사이에 공유한다.
- 속성은 색상만이 아니라 실루엣·무늬·상태 애니메이션으로 식별한다.
- 조준 중 최종 궤적과 정답을 노출하지 않는다.

## 적용 범위

상자·돌·젤리 래스터, 풍선·가시·홀·깃발 Canvas 상태, 벽 재질, 홀 포획 레이어를 [object_quality_audit.md](../art/object_quality_audit.md)와 [asset_registry.md](../assets/asset_registry.md)에 연결했다.
