## 상태·피벗 검증 규칙

- 프레임 상태는 코드의 이벤트 이름과 일치해야 한다.
- 상태 전환마다 콜라이더 활성 여부와 되감기 복원 상태를 기록한다.
- 허용 피벗 오차는 논리 좌표 2px 이내, 홀 깃발 앵커는 홀 중심에서 가로 12px 이내로 시작 기준을 둔다. 실제 캡처에서 조정하면 변경 이유와 커밋을 기록한다.
- 에셋 권리 상태가 `조건부 승인`이면 상용 사용을 단정하지 않고, 생성 도구 약관·프롬프트·입력 이미지·변환 전후 해시를 별도 확인한다.
