# 에셋 라이선스 검토

## 판정 게이트

1. 원본 페이지, 저작자, 접근일, 라이선스 원문과 파일 해시를 기록한다.
2. 상업 이용·수정·배포·표시·ShareAlike·DRM 조건을 각각 확인한다.
3. CC0도 원본 페이지와 접근일을 남긴다. CC BY는 저작자·링크·변경 사실을 남긴다.
4. NC, ND, 불명확한 개별 조건은 법무 검토 전 제품 자산으로 승인하지 않는다.
5. 생성 자산은 입력 이미지, 프롬프트 요약, 변환 이력, 생성 도구 약관 확인일을 기록한다.

## 현재 판정

- 게임 화면의 풍선·가시·홀·깃발 Canvas 표현은 자체 코드로 승인했다.
- 생성 상자·돌·젤리는 외부 입력이 없다는 기록이 있으나 생성 도구의 최신 약관 확인 전에는 조건부 승인으로 둔다.
- CC0 레거시 상자·돌은 출처와 해시를 보존하고, 최종 번들 사용 여부를 별도로 확인한다.
