# 게임성 전후 비교

## 변경 전

복사가 무제한이고 축약 화면의 조작 순서가 약했으며, 실패 뒤 다음 실험 방향과 반복 보상이 충분히 구체적이지 않았다.

## 현재

첫 3단계 시작 상태에는 복사권을 노출하지 않고, 3단계 클리어 보상으로 조건부 복제 코어를 획득하도록 구현했다. 보상은 다음 플레이에 남고 되감기·초기화 규칙과 분리되며, 속성 없는 경로와 기믹 우회 경로를 유지한다. 축약 HUD에는 발사 3단계 안내를, 실패 팝업에는 힘·각도·속성·충돌 상황별 안내를 추가했다.

## 남은 검증

실제 사용자가 첫 1~3회 안에 이해하고, 실패 후 행동을 바꾸며, 복사권을 가치 있게 느끼는지는 미검증이다.
