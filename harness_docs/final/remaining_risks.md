# 남은 위험

## 상용 수직 슬라이스 반복 추가 위험

- 대표 보드·조준 UI·직접 충돌 이벤트는 구현했지만 실제 iPhone/iPad에서 시각 밀도와 프레임 시간을 측정하지 않았다.
- `ShotImpact`는 물리 충돌의 위치·법선·대상·경로 시점을 기록한다. 재질별 합성 사운드 큐와 기본 플랫폼 햅틱을 연결했지만, 실제 iOS 햅틱 강도와 Web·iOS 청취 품질은 아직 검증하지 않았다.
- 첫 3스테이지가 초보자에게 1~3회 안에 성공되는지는 성공 영역 검색과 실제 사용자 테스트 전에는 확정할 수 없다.
- 속성 복사는 첫 챕터에서 숨기고 3단계 클리어 보상인 복제 코어로 조건부 제공하며, 되감기·초기화 복원을 구현했다. 실제 플레이테스트에서 희소 자원의 가치와 직관성은 아직 확인하지 않았다.
- `flutter build ios --no-codesign`은 Development Team·프로비저닝 프로파일 부족으로 배포용 빌드가 생성되지 않았다.

## 이번 반복에서 닫힌 항목

- 활성 공과 연쇄 물체에 1.25 단위 선분 검사와 이분 충돌점 보정을 적용했다.
- 홀과 장애물이 같은 선분에 있을 때 충돌 위치가 홀보다 앞선 경우만 홀 진입을 허용한다.
- iOS AppIcon 전 규격을 정사각형 전용 이미지로 교체했다.
- 1x1 런치 이미지 placeholder를 프로젝트 아이콘으로 교체하고 런치 배경을 게임 색상과 맞췄다.
- OpenGameArt 원본 HTML, CC0 법적 코드 HTML, 파일 해시와 권리대장을 보존했다.
- 물체·공 정보 팝업 설명의 줄 수 제한을 제거했다.
- 목업 리더보드는 `예시 기록`으로 명시했다.
- 충돌 후보를 물체별로 선분상 이른 시점에 정제하고 동률만 ID로 결정하도록 보강했다.
- 무거움 없는 공의 스위치 작동을 거절하고 문을 닫아 두는 규칙을 구현했다.
- HUD·조작 안내의 말줄임을 제거하고 정보 팝업을 화면 안에서 스크롤 가능하게 했다.
- 롱프레스 취소와 기록 로딩 선행을 추가하고 320x568 위젯 검사를 포함했다.
- 물리 QA가 연쇄 깊이 상한을 현재 엔티티 수에 맞게 확장하고 5단계 연쇄·배열 순서·프레임 독립성 테스트를 추가했다.
- 퍼즐 QA가 1·2라운드 대표 풀이와 우회 경로를 점검하고 맵 배치를 조정했다.
- 모바일 QA가 접근성 의미, 팝업 뒤 입력 차단, 좁은 화면 팝업을 검증했다.
- 기본 플랫폼 사운드·햅틱 피드백을 속성 선택, 발사, 충돌, 스위치, 젤리·홀, 클리어·별·메달·실패, 일시정지 흐름에 연결하고 연속 사운드 순서·중복 재생·미지원 플랫폼 예외를 흡수했다.
- 320x568·390x844 안전영역, HUD·컨트롤 비겹침, 조기 롱프레스 취소, 생명주기 충전 취소, 휴대폰별 한글 접근성 의미를 위젯 회귀로 검증했다.

- 실제 iPhone/iPad에서 터치 좌표, 프레임, 햅틱을 아직 검증하지 않았다.
- Xcode 16.2 환경에 iOS 18.2 Simulator Runtime이 없어 시뮬레이터 빌드 destination 검증이 아직 불가능하다.
- 실제 사용자 테스트가 없어 튜토리얼의 직관성과 시각 선호를 확정할 수 없다.
- 브라우저 390px 캡처로 한글 렌더링과 HUD를 확인했지만, iPhone 제출용 캡처는 아직 확보하지 않았다.
- 웹 데모의 물리 결과는 자동 테스트로 확인했지만 모든 레벨의 최소 샷 해를 수동으로 최적화하지 않았다.
- 사운드와 햅틱은 재질별 큐·Web 합성 톤·플랫폼 기본 피드백까지 연결했지만, 실제 기기 청취·햅틱 품질은 남아 있다.
- 결과 팝업의 추가 도전은 단계별 조건과 로컬 저장·재실행 표시까지 연결했지만, 실제 사용자가 선택형 목표를 이해하고 반복할지는 플레이테스트 전에는 확정할 수 없다. 본 클리어 성공과 분리되어 있어 특정 기믹을 강제하지 않는다.
- 섬 지도는 좌우 항해 경로로, 첫 단계는 바위 선택·공 충전 코치마크로 보강했지만 30초·5분 안에 실제 초보자가 이해하는지는 Web·위젯 증거만으로 확정할 수 없다.
- 애니메이션은 확정된 충돌 단계 이벤트를 재생하는 구조이며, 실제 기기에서 프레임 간격이 긴 경우에도 시각적 끊김이 없는지 확인이 필요하다.
- iOS Xcode 빌드는 완료됐지만 Development Team과 프로비저닝 프로파일이 없어 배포용 빌드가 실패했다.
- 실제 Bundle ID가 `com.example.propertyShot` 예시 값이므로 앱스토어 계정에 연결된 고유 Bundle ID가 필요하다.
- 개인정보 처리방침과 지원 문서는 초안이며 공개 URL과 운영 주체 검토가 필요하다.
- AppIcon·런치 이미지의 실제 iPhone/iPad 표시와 안전 영역은 실기기에서 확인하지 않았다.
- 후보가 거의 같은 선분에서 겹치는 동시 충돌의 30/60/120FPS 이벤트 시간축은 아직 실기·프레임 검증이 필요하다.
- 1~3라운드의 대표 속성 순서와 2단계 직선 우회 차단은 레벨 계약·단위 테스트에 반영했다. 실제 사용자 테스트와 모든 조준 각도의 최소 샷 최적화는 여전히 필요하다.
- 브라우저 캡처 기준으로 게임 캔버스와 HUD는 좁은 화면에서 제약을 받지만, 실제 iPhone safe area와 프레임 안정성은 실기기에서 다시 확인해야 한다.
- 앱스토어 제출 전 최종 IPA/번들 에셋 해시 대조와 TestFlight 플레이 세션이 필요하다.

## 2026-08-01 P0 반복 이후 추가 위험

- 연쇄 이동 공의 홀 선행 포획과 뒤 벽 충돌 차단은 순수 Dart 회귀로 검증했으며, 실제 렌더에는 홀 중심 이동·축소·페이드·흡입 링 VFX가 연결되어 있다. 다만 실기기 프레임 간격에서 이 연출이 끊김 없이 보이는지는 아직 검증하지 않았다.
- `ShotImpact` 대상 ID와 재질별 햅틱 강도·젤리·홀 전용 사운드 큐는 연결했지만, 실제 iOS 햅틱 강도와 재질별 사운드는 검증하지 않았다.
- 애니메이션 종료는 논리 커서 우선·예상시간 Timer 보조 구조다. 백그라운드 복귀와 30·60·120FPS에서 시각 종료가 정확히 일치하는지는 미검증이다.
- 첫 3단계는 독립 UX 진단에서 2단계 탄성 구분과 3단계 복잡도가 위험으로 재확인됐다. 실제 사용자 없이 직관성 통과로 기록하지 않는다.
- 3단계 점착 없는 직접 경로 `(1, -1.3), 힘 1`은 스위치·상자 연쇄·반사 후 홀 진입까지 순수 Dart 감사로 확인했지만, 실제 사용자에게 이 경로가 자연스럽게 발견되는지는 여전히 미검증이다.
- `dart run tool/physics_benchmark.dart`로 순수 `ShotResolver` 비용은 최신 실행에서 단계별 1회 평균 215.2~312.6µs로 측정했다. Canvas·이미지·실기기 프레임 비용은 포함하지 않으므로 실제 기기 성능 위험은 남아 있다.
