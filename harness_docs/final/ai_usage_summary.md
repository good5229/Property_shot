# AI 활용 내역

AI는 저장소 구조 분석, Dart/Flutter 코드 수정, 순수 Dart 시뮬레이션과 Flame 렌더링 연결, 테스트 추가, README·하네스 문서 작성을 보조했다. 외부 이미지 자산은 OpenGameArt의 CC0 `Smooth Physics Obstacle Props`를 사용했으며 출처는 README에 기록했다. 실제 사용자 반응이나 플레이테스트 결과는 생성하지 않았다.

## 2026-08-02 목표 감사 기록

- 작업 목적: 목표 파일의 상용 수직 슬라이스 완료 조건을 현재 코드·문서·데모와 대조하고, 축약 모바일 온보딩의 실제 공백을 보강했다.
- 제공된 컨텍스트: `harness_docs/` 전체 규칙, README, 현재 브랜치·커밋·서버, Flutter 코드·테스트·에셋.
- 프롬프트 요약: 비주얼 일관성, 초반 난이도와 다중 풀이, 속성 복사의 희소성, 충돌 피드백, 결정론, QA·성능·iOS 증거를 역할별로 독립 평가하고 구현 후 재평가한다.
- Subagent 결과: 축약 HUD의 발사 순서 누락, Canvas·래스터 질감 혼재, 3단계 정보량, 실제 기기·사용자 검증 공백을 확인했다.
- 채택한 변경: 초기 상태 메시지를 `방향 조정 → 공 길게 누르기 → 손 떼기`로 단축하고 320px 위젯 회귀를 추가했다. 보드 최소 폭을 침범하는 별도 행은 채택하지 않았다.
- 생성·수정 문서: 공유 컨텍스트, 난이도·복사·오브젝트·온보딩·피드백·기기 매트릭스, 전후 비교, 교차 검토, 다음 반복 기록.
- 검증: `dart format .`, `flutter analyze`, `flutter test` 105개, `flutter build web --release`, benchmark, 서버 루트·번들 HTTP 200.
- 사람의 검토가 필요한 내용: 실제 iPhone/iPad 프레임·메모리·햅틱, 초보자의 첫 3회 이해도, 복사권 가치와 반복 플레이 의향.
