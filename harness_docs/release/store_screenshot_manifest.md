# 스토어 스크린샷 명세

## 원칙

스토어 이미지는 실제 실행 화면을 캡처한다. 합성된 홍보 문구나 실제 빌드에 없는 기능을 넣지 않는다. 모든 화면의 UI 문구는 한글로 유지한다.

## 촬영 조건

- 웹 데모 또는 iOS 실행 빌드의 세로 화면을 사용한다.
- 기본 상태, 팝업 상태, 연쇄 반응 상태를 각각 별도 파일로 보존한다.
- 캡처 뒤 `file`과 이미지 뷰어로 실제 픽셀 크기·비어 있는 화면·문자 겹침을 확인한다.
- 실기기 캡처가 확보되기 전에는 웹 캡처를 `검증용`으로만 표시하고 제출 완료로 간주하지 않는다.

## 현재 상태

- `screenshots/iphone-portrait-gameplay-web-validation.png`는 한글 글리프와 게임판 렌더링을 확인하기 위한 웹 검증 캡처일 뿐, 실기기 제출 캡처가 아니다. 넓은 브라우저 뷰포트에서 게임판이 중앙에 배치되는 특성이 있어 스토어 제출 자료로 사용하지 않는다.
