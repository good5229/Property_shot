# 스토어 자산 기록

## 앱 아이콘

- 목적: iOS 홈 화면과 앱스토어 아이콘
- 파일: `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
- 원본: `assets/icons/property_shot_app_icon_source.png`
- 스타일: 공·무거움·탄성·점착을 글자 없이 보여주는 프로젝트 전용 귀여운 물리 장난감 아이콘
- 생성 방식: Codex 기본 이미지 생성 도구
- 생성 프롬프트 요약: 흰색 얼굴 공을 중심에 두고 회색 돌, 초록 탄성 고리, 보라 점착 젤리를 함께 배치한 정사각형 앱 아이콘. 글자·로고·워터마크 없음.
- 변환: iOS AppIcon 규격별 PNG 리사이즈

## 런치 화면

- 파일: `ios/Runner/Assets.xcassets/LaunchImage.imageset/`
- 앱 아이콘 원본을 중심 이미지로 사용하며, `LaunchScreen.storyboard`의 배경색과 연결한다.
- 실제 기기에서 안전 영역과 초기 표시 시간을 확인해야 한다.

## 게임 스프라이트

- 파일: `assets/generated/crate-v2.png`
- 목적: 게임 화면과 물체 속성 팝업의 상자 표현
- 생성 방식: Codex 기본 이미지 생성 도구로 신규 생성 후, 격리된 Pillow 환경에서 초록색 키 배경을 알파로 제거
- 생성 프롬프트 요약: 글자·기호·워터마크 없는 따뜻한 나무 상자, 세 방향이 보이는 입체 구도, 나무결과 금속 모서리, 작은 모바일 화면에서도 식별되는 고해상도 캐주얼 게임 스프라이트
- 검토 상태: 외부 입력 이미지는 없지만, 실제 상업 이용 전 사용 중인 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.
- 파일: `assets/generated/jelly-bumper-v1.png`
- 목적: 게임 화면과 물체 속성 팝업의 젤리 범퍼 표현
- 생성 방식: Codex 기본 이미지 생성 도구로 신규 생성 후, 격리된 Pillow 환경에서 초록색 키 배경을 알파로 제거
- 생성 프롬프트 요약: 글자·기호·워터마크 없는 반투명 민트색 젤리 범퍼, 둥근 물방울 실루엣과 내부 기포, 왼쪽 위 하이라이트, 부드러운 카툰 외곽선, 그림자 없는 투명 배경용 원본

- 검토 상태: 외부 입력 이미지는 없지만, 실제 상업 이용 전 사용 중인 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.

- 목적: 게임 화면과 물체 속성 팝업의 무거운 돌 표현
- 생성 방식: Codex 기본 이미지 생성 도구로 신규 생성 후, 격리된 Pillow 환경에서 초록색 키 배경을 알파로 제거

- 검토 상태: 외부 입력 이미지는 없지만, 실제 상업 이용 전 사용 중인 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.

## 섬 세계 배경

- 파일: `assets/generated/island-restoration-world-v1.webp`
- 목적: 홈과 섬 지도에서 관측소·등대·다리 복구라는 장기 목표를 하나의 세계 장면으로 전달
- 생성 방식: Codex 기본 이미지 생성 도구로 신규 생성한 PNG를 시각 검수한 뒤 품질 86 WebP로 변환했다. 외부 입력 이미지 없이 프로젝트의 기존 청록·모래·산호색 팔레트와 시설 설정만 사용했다.
- 생성 프롬프트 요약: 밝은 해안 섬을 동화책처럼 내려다보는 세로형 모바일 배경. 관측소, 외딴 등대, 수리 중인 나무다리와 이들을 잇는 작은 황금빛 경로를 배치하고 UI가 올라갈 중앙에는 저밀도 여백을 둔다. 손으로 칠한 듯한 부드러운 2D 형태와 명확한 모바일 실루엣을 사용하며 글자·로고·워터마크·특정 작품 모방을 금지한다.
- 검토 상태: 화면 위 텍스트 대비와 모바일 크롭을 Golden으로 확인한다. 외부 입력은 없지만 실제 상업 이용 전 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.

## 화면 캡처

스토어 제출용 캡처는 실제 게임 화면에서 생성하며, 장식용 합성 이미지를 사용하지 않는다. 파일명·해상도·검수 항목은 [`store_screenshot_manifest.md`](store_screenshot_manifest.md)에 고정한다.

## 앱스토어 제출 전 미완료 자료

- 웹 검증 캡처는 존재하지만 제출용 실기기 캡처가 아니다.

- 개인정보 처리방침 URL
- 지원 URL
