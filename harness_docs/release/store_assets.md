## 앱 아이콘

- 목적: iOS 홈 화면과 앱스토어 아이콘
- 파일: `ios/Runner/Assets.xcassets/AppIcon.appiconset/`
- 원본: `assets/icons/property_shot_app_icon_source.png`
- 스타일: 공·무거움·탄성·점착을 글자 없이 보여주는 프로젝트 전용 귀여운 물리 장난감 아이콘
- 생성 방식: Codex 기본 이미지 생성 도구

### 문·스위치·풍선 기믹

- 파일: `assets/generated/gate-closed-v1.png`, `assets/generated/switch-pad-v1.png`, `assets/generated/balloon-v1.png`
- 목적: Canvas 기호로 그리던 문·스위치·풍선을 첫 항해 삽화와 동일한 캐주얼 물리 장난감으로 표현한다.
- 생성 방식: Codex 기본 이미지 생성 도구의 내장 생성 모드를 사용했고, 프로젝트 내부 `stage-icon-bouncy-v1.png`만 팔레트·외곽선·질감 참고로 입력했다. 최종 RGBA PNG를 최대 640px로 축소했다.
- 생성 프롬프트 요약: 청록·모래·산호색 팔레트, 짙은 청록 외곽선, 둥근 모서리와 따뜻한 크림 하이라이트를 사용한다. 문은 중앙 이음선이 선명한 두 패널, 스위치는 눌러지는 금색 원형 패드, 풍선은 충돌 시 압축되어도 읽히는 산호색 단일 실루엣으로 만들며 글자·UI 프레임·인물·로고·워터마크·특정 작품 모방을 금지했다.
- 상태 표현: 문은 동일 스프라이트의 좌우 절반을 실제 개방 진행률만큼 이동하고 세로 문은 렌더 단계에서 회전한다. 스위치는 눌림 시 세로 압축·초록 활성색·펄스 링을, 풍선은 충돌 시 압축을 적용하며 파열 상태는 짧은 Canvas 파편 연출을 유지한다. 물리 충돌체와 판정 위치는 이미지 크기와 독립적으로 기존 데이터를 사용한다.
- 검토 상태: 390×844·768×1024 게임 화면과 문 개방·스위치 눌림·풍선 파열 Golden에서 판정 위치, 회전, 크롭, 상태 구분을 확인한다. 실제 상업 이용 전 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.

## 섬 세계 배경

- 파일: `assets/generated/island-restoration-world-v1.webp`
- 목적: 홈과 섬 지도에서 관측소·등대·다리 복구라는 장기 목표를 하나의 세계 장면으로 전달
- 생성 방식: Codex 기본 이미지 생성 도구로 신규 생성한 PNG를 시각 검수한 뒤 품질 86 WebP로 변환했다. 외부 입력 이미지 없이 프로젝트의 기존 청록·모래·산호색 팔레트와 시설 설정만 사용했다.
- 생성 프롬프트 요약: 밝은 해안 섬을 동화책처럼 내려다보는 세로형 모바일 배경. 관측소, 외딴 등대, 수리 중인 나무다리와 이들을 잇는 작은 황금빛 경로를 배치하고 UI가 올라갈 중앙에는 저밀도 여백을 둔다. 손으로 칠한 듯한 부드러운 2D 형태와 명확한 모바일 실루엣을 사용하며 글자·로고·워터마크·특정 작품 모방을 금지한다.
- 검토 상태: 화면 위 텍스트 대비와 모바일 크롭을 Golden으로 확인한다. 외부 입력은 없지만 실제 상업 이용 전 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.

- 프롬프트 요약: 청록·모래·산호 팔레트, 짙은 청록 외곽선, 둥근 장난감 형태, 따뜻한 크림 하이라이트, 모바일 30~128px에서도 읽히는 하나의 중심 사물. 타륜·접힌 지도·필름 릴·해돋이 깃발·활동 카드·열쇠·랜턴과 섬 시설을 표현하고 글자·UI 프레임·인물·워터마크·특정 작품 모방을 금지했다.

- 검토 상태: 홈 320/390/768, 섬 지도 320/390/768, 복구 3상태와 완료 연출 Golden에서 크롭·텍스트 우선순위·상태 구분을 확인한다. 실제 상업 이용 전 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.

## 첫 항해 단계 삽화

- 파일: `assets/generated/stage-icon-*-v1.png` 10종
- 목적: 돌·상자·젤리의 반복 사용과 작은 Material 기호를 없애고, 각 단계에서 배우는 인과를 카드만 보고도 구분하게 한다.
- 생성 방식: Codex 기본 이미지 생성 도구에서 프로젝트 내부 `stone-v2.png`, `jelly-bumper-v1.png`만 시각 참조로 사용해 단계별로 별도 생성했다. 배경이 불투명하게 생성된 결과는 동일 이미지 편집 단계로 외곽 배경만 제거했으며 최종 10종 모두 알파 채널을 확인하고 최대 640px로 축소했다.
- 프롬프트 요약: 짙은 청록 갈색 외곽선, 따뜻한 크림 하이라이트, 손으로 칠한 입체 질감, 72px에서도 읽히는 하나의 중심 행동. 단계별 행동은 상자 밀기, 두 번 반사, 스위치에서 문 열기, 풍선 터뜨리기, 속성 이전, 가속 발판, 잔류 공 쿠션, 세 대상 연쇄, 회전 반사판, 네 속성 종합으로 제한하고 글자·숫자·UI 프레임·워터마크를 금지했다.
- 검토 상태: 섬 지도 320×568, 390×844, 768×1024, 1024×768, 1440×900 Golden에서 실제 표시 크기·잠금 회색 처리·텍스트와의 균형을 확인한다. 1440px 이상에서는 본문을 최대 1180px로 중앙 정렬해 이미지가 넓은 빈 공간에 묻히지 않도록 한다. 실제 상업 이용 전 이미지 생성 도구의 최신 이용약관과 산출물 권리 정책을 최종 확인한다.
