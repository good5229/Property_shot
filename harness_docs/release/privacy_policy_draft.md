# 개인정보 처리방침 초안

이 문서는 실제 공개 URL로 배포하기 전 검토용 초안이다.

## 수집 정보

현재 데모 빌드는 계정, 이름, 연락처, 위치, 광고 식별자를 수집하지 않는다. 온라인 리더보드와 분석 SDK도 연결되어 있지 않다.

## 기기 저장

로컬 최고 기록은 사용자 기기 안에만 보관하며, 앱 삭제 또는 사용자의 기기 설정 초기화로 삭제된다. 계정과 서버 동기화는 사용하지 않는다.

## 외부 전송

현재 게임 플레이 데이터와 외부 에셋 정보는 서버로 전송하지 않는다.

## 문의

출품 전에 운영 주체의 지원 이메일과 공개 지원 URL을 확정해 이 문서에 추가한다. 현재 저장소에는 공개 URL을 임의로 기재하지 않는다.

## 검토 상태

스토어 제출 전 법무·운영 담당자의 검토와 실제 공개 URL 게시가 필요하다.
