# 앱스토어 제출 자료

## 앱 이름

속성 한방

## 한 줄 소개

공에 속성을 담아 물체를 밀고, 튕기고, 붙여 홀에 넣는 물리 퍼즐

## 설명문 초안

공 주변을 길게 눌러 방향과 힘을 정하고 손을 떼세요. 무거움·탄성·점착 속성을 옮기거나 복사해 상자와 돌을 밀고, 젤리와 벽을 이용해 길을 만듭니다. 스위치를 누르면 문이 열리고, 이전에 발사한 공도 다음 충돌에 참여합니다.

모든 스테이지는 한글 UI와 짧은 물리 실험으로 구성됩니다. 같은 스테이지를 더 적은 발사 횟수로 다시 풀어 나만의 기록을 갱신하세요.

## 키워드 초안

물리 퍼즐, 공 게임, 탄성, 무거움, 점착, 조준, 충돌, 캐주얼 퍼즐

## 제출 전 필수 확정값

- [ ] 실제 Bundle ID
- [ ] 앱스토어 Connect 팀과 Development Team
- [ ] 개인정보 처리방침 공개 URL
- [ ] 지원 URL
- [ ] 연령 등급 설문 답변
- [ ] 실제 기기 스크린샷
- [ ] 앱 아이콘·런치 화면 실기기 확인
- [ ] 외부 에셋 출처 표기와 권리대장 첨부

## 접근성 안내

- 주요 조작 버튼에는 한국어 이름과 아이콘 설명이 있다.
- 게임판에는 공의 속성 확인, 조준·힘 조절 방법을 한국어로 제공한다.
- 안내 메시지는 보조기술의 실시간 영역으로 전달한다.
- 색상만으로 속성을 구분하지 않고 아이콘·무늬·텍스트를 함께 사용한다.
