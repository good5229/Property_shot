# 연령 등급 답변 초안

이 문서는 실제 스토어 설문에 입력하기 전의 사실 확인용 초안이다.

## 현재 데모 기준

- 폭력: 없음. 공과 물체의 비현실적 물리 충돌만 표현한다.
- 성적 콘텐츠 또는 노출: 없음.
- 욕설·비속어: 없음.
- 도박·확률형 구매·현금 거래: 없음.
- 공포·고어·현실적 상해 표현: 없음.
- 사용자 생성 콘텐츠·채팅·외부 링크: 없음.
- 광고·추적·로그인: 없음.

## 임시 판단

현재 콘텐츠 설명만 기준으로는 낮은 연령 등급 후보로 검토한다. 최종 등급은 Apple의 최신 설문 문항과 실제 출시 빌드를 기준으로 운영 담당자가 확정한다.

## 검토 전제

- 신규 콘텐츠나 광고 SDK를 추가하면 이 문서를 다시 검토한다.
- 외부 리더보드·계정·결제 기능을 추가하면 등급과 개인정보 자료를 다시 작성한다.
