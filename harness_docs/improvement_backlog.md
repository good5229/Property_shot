# 개선 백로그

## P0

- 없음. 현재 정적 분석과 핵심 신규 테스트는 통과했다.

## P1

- 4단계 고해상도 성공 영역을 실제 분석해 뾰족함 독점 여부를 확인한다.
- 연쇄 안전 종료 이벤트에 중단 엔티티·반복 횟수·잔여 속도를 추가한다.
- 팝 후 문 열림을 실제 화면 캡처에서 확인한다.
- `ImpactMetrics`를 실제 히트 스톱 타이머와 모션 감소 설정에 연결한다.

## P2

- 풍선·성게 전용 래스터 자산과 권리대장을 추가 검토한다.
- Canvas와 래스터 물체의 외곽선·그림자·광원 강도를 맞춘다.
- 풍선 단계 Golden과 5개 해상도 Web 캡처를 추가한다.
- iOS 서명·시뮬레이터·실기기 검증을 수행한다.
