# 풍선·뾰족함 참고자료 매트릭스

## 목적

풍선과 뾰족함을 기존 해변 장난감 톤에 맞는 독립 수직 슬라이스로 검증한다. 풍선은 일반 공에 밀리거나 반사되며, 뾰족함 공에만 터진다. 뾰족함은 풍선 외 물체를 관통하지 않는다.

| 대상 | 형태 언어 | 상태 | 충돌 규칙 | 화면 단서 | 검증
|---|---|---|---|---|---|
| 풍선 | 산호색 비대칭 타원, 매듭, 끈 | intact / pushed / popped / inactive | 일반 공은 밀림·반사, 뾰족함은 팝 | 반사광·끈·팝 이동 이벤트 | `balloon_physics_test.dart`
| 뾰족함 공급 물체 | 둥근 성게 장난감과 짧은 가시 | ready / drained | 고정 공급원, 속성 이전·복사 | 색상 외 가시 실루엣 | `sharpness_property_test.dart`
| 뾰족함 공 | 공 뒤쪽의 작은 가시 | equipped / consumed | 풍선에 1회 특수 작용 | 공 표면 무늬와 가시 | 속성 테스트·Golden
| 연결 문 | 붉은 문과 열림 색 | closed / opening / open | 풍선 팝 후 비고정·통과 | `opening` 이동 이벤트 | 물리 이벤트 순서

## 아트 기준

- 광원은 기존 화면과 같은 왼쪽 위다.
- 외곽선은 짙은 청록색, 그림자는 오른쪽 아래다.
- 풍선 일반 충돌은 눌림과 복원을 보이고, 팝은 팝 이동과 연결 문 열림을 순서대로 보인다.
- 신규 문구는 모두 한글이며 `속성 없음`, `뾰족함 장착`, `풍선은 밀렸지만 터지지 않았습니다`를 기본 표현으로 사용한다.
- 생성 또는 직접 작성한 신규 도형은 출처 제한이 없는 코드 자산으로 기록한다. 기존 래스터 자산은 별도 권리 검토가 필요하다.

## 수직 슬라이스 품질 기준

- 390×844에서 풍선이 40 논리 픽셀 이상으로 식별된다.
- 일반 충돌과 팝이 색상만이 아니라 눌림·팝·잔여 상태로 구분된다.
- 홀과 후속 물리 대상이 팝 효과에 가려지지 않는다.
- 4단계는 풍선을 터뜨리지 않는 우회 가능성을 데이터 계약으로 남긴다.
