## 공통적으로 가져올 원칙

1. 조작 대상과 목표를 첫 화면에서 식별한다.
2. 한 번에 하나의 규칙을 소개한다.
3. 실패를 다시 시도할 이유로 바꾼다.
4. 물리 결과를 짧고 명확한 타격감으로 전달한다.
5. 추천 풀이와 실제 성공 조건을 분리한다.

## 적용 제한

이 표는 공식 상점의 현재 소개·제품 포지셔닝을 참고한 비교 프레임이다. 특정 게임의 내부 물리 구현이나 성공 지표를 사실로 복사하지 않으며, 최종 구현은 `속성 한방`의 결정론 규칙과 테스트가 결정한다.
