# 모바일 퍼즐 레퍼런스 매트릭스

## 차별화 원칙

- Property Shot의 핵심은 환경 물체의 속성을 공에 담아 연쇄 반응을 설계하는 것이다.
- 해변 실험 섬 테마를 사용하되 특정 게임의 캐릭터, UI 배치, 레벨, 아이콘, 에셋, 색상 조합을 복제하지 않는다.
- 온라인 랭킹·결제·광고·서버 시스템은 구현 범위에서 제외한다.
