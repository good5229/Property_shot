# 현재 Goal 기록

첨부된 `속성 한방 지속 고도화 — Subagent 협업 기반 Codex 작업 프롬프트`를 현재 반복의 작업 지시로 사용했다. 핵심은 기존 코드를 보존하고 여섯 역할을 독립적으로 활용한 뒤 교차 검토하여, 고속 충돌·결정론·연쇄 애니메이션·튜토리얼·QA 위험을 검증 가능한 코드와 문서로 개선하는 것이다.

2026-08-03 전체 Goal은 역할별 매뉴얼 선행 구축, 공식·신뢰 웹 참고자료, 에셋 권리 게이트, 스테이지4 인과, 홀·깃발 레이어, UX 문구, 자율 제안 평가, 자동·시각·접근성 QA, 원자적 Push와 최신 서버 증거까지 포함한다. 현재 반복의 요구사항별 증거는 [Goal 완료 감사](../final/goal_completion_audit_2026-08-03.md)에 연결한다.

## 2026-08-06 활성 Goal

원문은 Codex 첨부 파일 `pasted-text-1.txt`의 `속성 한방(Property Shot) 10스테이지 확장 및 상용화 품질 개발 총괄 프롬프트`다. 원문 전체를 읽고 구현 요구, 불변 조건, Sol·Luna 협업 절차, 테스트·릴리스 게이트를 현재 작업 지시로 채택했다.

목표는 현재 4개 단계를 데이터 기반 10개 단계로 확장하고, 단계별 3~4개 검증 패턴, 결정론적 셔플 백과 런 저장, 패턴 검증기, 신규 기물, 프레임 독립 입력, 점수·보상·오늘의 도전·리플레이·설정을 실제 제품 흐름으로 통합하는 것이다. 기존 1~4단계 경로, 결정론적 `ShotResolver`, Flame 재생 분리, 벽 불변, 과거 공 유지, 홀 우선 성공, 복수 해법, 한글 UI, 이전 저장 호환은 계속 지켜야 한다.

메인 작업자는 Sol로서 구조 결정과 통합 판정을 맡고, 분리 가능한 구현은 Luna에 작업 ID 단위로 지시한다. Luna 결과는 Sol이 변경점과 회귀를 직접 검증해 PASS한 뒤에만 개별 commit·push한다. 세부 순서와 증거 게이트는 [10단계 확장 실행 계획](../plans/stage_10_expansion.md)에 기록한다.
