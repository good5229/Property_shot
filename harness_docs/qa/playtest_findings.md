작성 기준: 2026-08-03 KST
상태: 외부 플레이테스트 전

## 현재 확인된 사실

- 자동 위젯 테스트에서 홈·섬 지도·플레이·클리어 흐름을 확인했다.
- 웹 캡처에서 한글 HUD, 속성 팝업, 지도 4단계 카드, 잠금 표시를 확인했다.
- 자동 물리 탐색에서 단계별 추천 경로와 일부 우회 경로를 확인했다.
- 자동 계측은 물체 확인, 속성 이전·복사, 조준·충전·발사, 충돌, 홀, 스위치, 문, 풍선, 점착 상태를 구분해 기록한다.

위 결과는 실제 사용자가 규칙을 이해했다는 증거가 아니다.

## 예정된 참여자 구성

최소 12명으로 진행한다. 퍼즐 경험이 적은 사용자 4명 이상, 보통 사용자 4명 이상, 물리 퍼즐 경험자 4명 이상을 포함한다. 왼손잡이·작은 화면·태블릿 사용자를 별도로 포함한다.

## 진행 방법

개발자는 첫 플레이 동안 규칙을 설명하지 않는다. “첫 번째 섬을 플레이해 주세요”라는 문장만 전달하고, 첫 클릭 대상·잘못된 클릭·발사 버튼 탐색·실패 후 반복 행동·다른 풀이 탐색을 기록한다. 세션 뒤에는 속성 이전 결과, 원본 물체 변화, 충돌 예측 가능성, 재도전 의사를 질문한다.

## 판정 전 주의사항

실제 참가자 로그와 인터뷰 요약이 추가되기 전에는 튜토리얼 이해도·난이도·복수 풀이 발견을 통과로 표시하지 않는다. 정답 경로를 알려주는 관찰자 개입도 금지한다.
