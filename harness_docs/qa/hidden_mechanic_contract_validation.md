# 숨은 기믹 계약 검수

## 검수 범위

- 생산 카탈로그 10단계, 40개 패턴 전체
- 시작 공·홀·일반 기물의 화면상 겹침
- 숨은 기믹의 공개 조건과 공개 전 문구
- 필수 기믹을 거치지 않는 시작점-홀 직선 경로

## 결과

- 조건부로 정체가 공개되는 기믹은 4단계의 4개 패턴뿐이다.
- 각 `? 상자`는 자신에게 연결된 풍선 하나만 공개 트리거로 가진다.
- 4번 배치도 첫 풍선이 아니라 연결된 두 번째 풍선이 트리거로 선택된다.
- 공개 전 보너스 목표와 힌트는 `스위치`라는 정답을 말하지 않고 `? 상자`의 변화만 안내한다.
- 필수 기믹 패턴에 시작점-홀 무충돌 직선 경로가 생기면 빌드 검증에서 실패한다.
- 홀·범퍼와 상자·풍선에서 발견한 시각 겹침은 물리 풀이 범위를 유지하면서 표시 크기와 위치를 분리했다.

## 자동 실패 조건

`StagePatternValidator`는 다음 변경을 배포 전에 거부한다.

1. 숨은 기믹에 공개 트리거가 없거나 둘 이상인 경우
2. 현재 게임이 지원하지 않는 기물이 공개 트리거인 경우
3. 공개 전 힌트가 숨은 기믹의 실제 이름을 누설하는 경우
4. `gimmick_required` 패턴에서 아무 기물도 만나지 않고 홀에 도달하는 경우
5. 서로 다른 두 기물의 표시 영역이 의미 있게 겹치는 경우

검수 기준은 물리 충돌 영역과 화면에 보이는 이미지 영역을 따로 계산한다. 따라서 풀이 감각을 바꾸지 않고도 겹쳐 보이는 배치를 차단할 수 있다.
