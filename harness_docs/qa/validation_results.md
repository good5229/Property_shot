## 상용 수직 슬라이스 반복 추가 검증

- 보드 바깥 배경·목재 프레임·잔디 필드의 시각 계층을 추가했다.
- 조준 화살표와 파워 게이지의 색상·그림자·끝점 표시를 분리했다.
- 저파워·고파워 실패 원인 이벤트를 추가했다.
- 활성 공의 직접 충돌과 홀 포획을 `ShotImpact`로 기록했다.
- 충돌 위치·법선·대상·경로 시점 단위 테스트를 추가했다.
- 활성 공·연쇄 물체의 충돌을 `ShotImpact`로 통합하고, 연쇄 이동 경로를 누적 거리로 재생하도록 보정했다.
- `ShotImpact`에 실제 대상 ID를 추가하고 연쇄 공의 홀 선행 포획·벽 충돌 차단 회귀를 추가했다.
- 충돌 재질별 햅틱 강도와 진행률 기반 문 개방 연출을 연결했다.
- 첫 2단계 성공 입력을 2도·0.02 파워 간격으로 스캔하는 난이도 회귀를 추가했다. 연결된 성공 영역은 1단계 각도 16도·파워 0.86·최대 248셀, 2단계 각도 16도·파워 0.72·최대 223셀이다.
- 1·2단계의 홀 크기를 42 단위로 조정해 성공 영역을 넓혔고, 각도·파워 격자의 연결 성분을 자동 검증한다.
- 가상 30·60·120Hz 애니메이션 회귀에서 충돌 이벤트 중복 없음과 완료 콜백 단일 실행을 확인했다.
- 무거운 충돌은 플랫폼 알림음, 일반·탄성·점착 충돌은 플랫폼 클릭음으로 구분하는 매핑과 회귀를 추가했다.
- 젤리 범퍼를 생성 RGBA 스프라이트로 교체하고 게임 화면·물체 썸네일에 연결했다. 속성 보유 점멸은 이미지 렌더 경로에서도 유지하며, 젤리 원본 비율과 알파 가장자리를 보정했다.
- 하드 키 변환으로 젤리 하이라이트 내부 투명 구멍을 줄였고, 충돌 시 젤리 물결·방울 보조 연출을 추가했다. 최신 Web 빌드의 젤리 자산 응답도 HTTP 200으로 확인했다.
- 벽에 장난감 레일의 세로 이음새와 리벳을 추가하고 홀 깃발에 미세한 흔들림·하이라이트를 추가했다. 물리 판정과 히트박스는 변경하지 않았다.
- 조준 화살표를 분절 샤프트·채워진 화살촉으로 바꾸고 힘 게이지에 구간 표식을 추가했다. 최종 궤적은 노출하지 않으며 조준·힘의 역할을 분리한다.
- 복사 모델 결정 전 안전한 UI 개선으로 `떼어 공에 옮기기`와 `원본에 남기고 공에 복사하기` 문구를 적용했다. 복사 소모·복원 규칙과 물리 판정은 변경하지 않았다.
- 이전·복사 원본 결과 안내 위젯 회귀 테스트를 추가했으며 전체 테스트 기준은 100개로 갱신했다.
- 전체 테스트 100개 통과와 `flutter analyze` 통과를 확인했다.
- Playwright Chromium 캡처로 390x844와 1280x900 화면을 확인했다. 모바일 한글 안내·목표·오브젝트·하단 조작 영역의 말줄임·겹침이 없고, 데스크톱 보드 중앙 배치와 최종 궤적 비노출 조준이 유지된다.
- 같은 390x844 화면에서 돌을 실제 좌표 클릭해 속성 팝업을 열고 돌 아이콘·설명·이전·복사 버튼을 확인했다. Flutter Web 캔버스 접근성 DOM 직접 조회는 별도 미지원이며, 위젯 접근성 회귀로 보완한다.
- 이전 버튼까지 실제로 눌러 팝업 종료, 원본 선택 상태 해제, 공의 `공: 무거움` 표시 전환을 확인했다.
- 연결된 성공 영역과 가상 프레임 시간축은 자동 검증했지만 실제 초보자 이해도는 증명하지 않는다. Canvas 픽셀 골든, 실제 30·60·120FPS 프레임 측정, iOS 실기기, iPhone/iPad 햅틱도 아직 미검증이다.

## 2026-08-02 다중 풀이·표시 비율 재검증

- 3단계에서 속성 없이 `switch_pressed`·`sticky_attached`를 발생시키지 않고 `GamePhase.success`에 도달하는 경로를 2도·0.02 파워 격자로 자동 탐색했다.
- 젤리 스프라이트의 표시 폭을 엔티티 물리 폭에 맞췄다. 작은 화면의 보드 최소 폭 계약은 기존 위젯 테스트로 다시 통과했다.
- 데스크톱 HUD의 조준 안내는 `화면을 움직여 조준하고, 공을 0.45초 이상 누른 뒤 손을 떼세요.`로 고정했다. 모바일에서는 별도 줄을 추가하지 않아 보드 우선 레이아웃을 보존한다.
- 최신 전체 회귀 기준은 101개이며, 실제 사용자 플레이테스트·iOS 실기기·Canvas 픽셀 골든은 미검증이다.
- 최신 Web release를 기존 8080 프로세스 종료 후 교체하고 Playwright로 390x844·1280x900을 캡처했다. 모바일 보드 최소 폭·한글 HUD·조준 UI의 겹침이 없고, 데스크톱 HUD의 손가락 아이콘 안내가 표시된다.
- 첫 단계 메시지에 발사 순서를 보강한 최신 Web 빌드를 다시 캡처했다. 390x844 화면에서 `공을 길게 눌렀다 손을 떼 발사` 문장이 잘리지 않고 보드 최소 폭도 유지된다.
