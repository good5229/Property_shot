# 최종 흐름 Golden 검증

작성 기준: 2026-08-08 KST

## 목적

실패 원인을 이해하는 화면과 10단계 런을 마친 결과 화면이 실제 도메인 결과를 정확히 표시하고, 휴대폰·태블릿 크기에서 잘리거나 겹치지 않는지 고정한다.

## 검증 입력

- 실패 재생: 생산 1단계 패턴에 방향 `(-1, 0)`, 힘 `0.2`의 샷을 실제 `ShotResolver`로 실행한다. 실패 phase와 실제 impact 목록이 존재해야 화면을 만든다.
- 런 결과: `StagePatternSession`으로 10단계 패턴을 선택하고 3회 발사·1,970점으로 완료한다. 보상을 준비·선택하고 런 완료를 저장한 뒤 `PropertyShotApp` 시작 흐름에서 복원한다.
- 저장소: 테스트용 `SharedPreferences` 위에 생산 A/B `RunState` 저장소를 그대로 사용한다.

## 화면 판정

| 화면 | 390×844 | 768×1024 |
|---|---|---|
| 실패 재생 | 통과 | 통과 |
| 10단계 런 결과 | 통과 | 통과 |

실패 화면은 제목·설명·재생 행동·마지막 접촉·충돌 순서·홀 최근접 설명·닫기 버튼을 모두 표시한다. 런 결과는 총점 1,970점, 총 발사 3회, 획득 보상 1개와 홈 이동 행동을 표시한다.

## 실행 명령

```bash
flutter test test/final_flow_golden_test.dart test/failure_replay_test.dart test/widget_test.dart
flutter analyze
```

결과는 테스트 86개 통과, 정적 분석 오류 0건이다. Golden은 레이아웃과 호스트 렌더링 회귀를 검증하지만 실제 iOS·Android의 글꼴, 색, 햅틱, 터치 영역과 Safe Area를 대체하지 않는다.
