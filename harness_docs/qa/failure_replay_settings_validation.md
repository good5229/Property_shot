# PS-UX-02 실패 인과 재생·설정 검증

## 범위

- 실패 직전 약 3초를 기존 `ShotResult` 타임라인으로 반속도 재생한다.
- 재생은 최종 판정을 다시 계산하지 않으며, 원본 발사 시작 상태와 결과를 읽기 전용으로 사용한다.
- 실패 원인, 충돌 순서, 마지막 접촉 대상, 홀 최근접 위치를 한글로 표시한다.
- 실패 팝업에서 인과 재생, 다시 조준, 입력 조정을 선택할 수 있다.
- 마지막 샷 속도, 충돌 순서, 마지막 접촉, 홀 최근접 위치, 속성 발동,
  기믹 인과, 충돌 경로 아이콘, 연쇄 점수 상세, 진동, 저모션,
  화면 흔들림, 강한 점멸, 효과음, 배경 음악을 개별 설정한다.
- 설정은 `SharedPreferences`에 저장하고 스키마 버전 3으로 마이그레이션한다.
- 도움말 다시 보기는 다음 플레이 진입에서 도움말을 한 번 표시하고 소비 기록을 저장한다.

## 자동 검증

- `test/failure_replay_test.dart`: 원인·충돌 표기와 분석 과정의 상태 불변을 검증한다.
- `test/game_feedback_test.dart`: 기존 설정 마이그레이션, 14개 개별 설정의
  복원·안정 키 저장, 흔들림 강도, 도움말 다시 보기 저장을 검증한다.
- `test/settings_widget_test.dart`: 320x568 화면과 큰 글자 배율 1.5에서
  14개 설정을 모두 찾고 스크롤 조작하며, 다음 플레이에서 도움말이 한 번
  표시되는지 검증한다.
- `test/creative_chain_score_summary_test.dart`: 상세 설정을 꺼도 총점은
  유지되고 가산 근거만 숨는지 검증한다.
- `test/widget_test.dart`: 실패 팝업에서 인과 재생을 열고 닫은 뒤 기존 재시도 흐름이 유지되는지 검증한다.

PS-SETTINGS-03 집중 회귀 114개와 `flutter analyze` 이슈 0건을 확인했다.

## 수동 검증 잔여 항목

- 실제 iOS·Android 기기에서 효과음, 진동, 모션 감소, 카메라 흔들림 강도를 확인한다.
- 배경 음악은 새 외부 음원·패키지를 추가하지 않는 범위에서 기존 Web Audio
  합성 큐를 7초 간격으로 재사용한다. 네이티브에서는 효과음 경로가 무음
  대체 구현이므로 실제 연속 배경 음악 품질은 후속 음원 정책 확정 뒤 검증한다.
- VoiceOver·TalkBack에서 재생 화면, 충돌 순서, 설정 컨트롤의 한글 접근성 라벨을 확인한다.
- 큰 글자 최댓값에서 실패 팝업과 설정 메뉴의 세로 스크롤 및 버튼 접근성을 확인한다.
