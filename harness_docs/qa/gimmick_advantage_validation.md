# 전체 스테이지 기믹 우위 검증

## 판정 기준

- 대상: 10단계 × 생산 패턴 4개 = 40개 패턴.
- 1–6단계와 9단계: 각도 4도 간격 × 힘 10% 간격의 결정론 격자를 비교한다. 32개 모든 개별 패턴에서 기믹 성공 영역이 무기믹 우회보다 최소 1.40배 넓어야 한다.
- 7단계: 대표 준비 샷이 typed 잔류 공 인과를 만들고, 같은 900개 최종 입력에서 준비 상태 성공 영역이 초기 상태의 무기믹 우회보다 각 패턴에서 엄격히 커야 한다. 4패턴 합계는 최소 1.40배다.
- 8단계: 과거 공을 포함한 대표 연쇄 점수는 같은 홀 진입 직행 점수의 1.45배 이상이어야 한다.
- 10단계: 대표 첫 샷이 패턴 전용 문을 정확히 `closed+solid → open+non-solid`로 바꾸고, 준비 없는 같은 최종 입력은 실패해야 한다. 같은 900입력에서 준비 상태 성공 영역이 무기믹 우회보다 각 패턴에서 엄격히 크고, 4패턴 합계가 최소 1.40배여야 한다.
- 공통: 대표 해법, 주변 입력, 결정론, 정적 배치, 리플레이·저장 복원 회귀를 함께 통과해야 한다.

## 배치 보강

- `stage_bouncy_01`: 홀을 우상단으로 옮기고 하단 경로 벽을 추가했다. 900점 격자에서 탄성 19, 무속성 5다.
- `stage_bouncy_03`: 홀을 상단으로 옮기고 세로 경로 벽을 추가했다. 900점 격자에서 탄성 23, 무속성 0이다.
- 강화로 2단계의 절대 성공 입력 폭이 좁아진 점은 분석 기반 파를 2회에서 3회로 완화해 기록·별점 여유에 반영했다.
- `stage_rotating_reflector_01`, `_03`: 잠긴 `rotation_gate`를 추가했다. 반사판 회전 사건이 문을 열며 저장·재개 뒤에도 열린 상태와 회전 방향이 보존된다. 직접 우회는 남지만 성공 영역은 각각 17점, 11점으로 제한된다.

## 해석과 한계

- 이 검사는 가능한 모든 실수 입력을 증명하는 연속 수학 검사가 아니라, UI가 허용하는 범위를 균등 샘플링한 결정론적 회귀다.
- 우회 해법 자체는 창의적 풀이를 위해 남겨 두되, 의도 기믹은 더 넓은 성공 영역·더 높은 점수·필수 인과 중 하나를 제공한다.
- 실제 신규 사용자 성공률과 체감 난이도는 별도 외부 플레이테스트가 필요하다.
