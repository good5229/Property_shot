# 난도·학습·반복 루프 검증

검증 기준: 2026-08-25 KST

## 난도 조정 원칙

- 실제 `ShotResolver`와 고정 시드 가상 플레이를 함께 사용한다.
- 한 번에 한 변수군만 변경하고, 대표 해법·선택 도전·기믹 우위가 깨지면 변경을 폐기한다.
- 기물 충돌 범위 확대가 연쇄 순서를 바꾸는 경우에는 쉬워지더라도 채택하지 않는다.
- 의도한 반사 경로를 수행한 뒤 홀 가장자리에서 발생하는 근접 실패만 제한적으로 구제한다.

## 폐기한 후보

- `balloon_b`, 비워진 속성 원본, 속도 발판, 회전판의 충돌 범위를 직접 넓히는 후보는 대표 해법의 충돌 순서나 성공을 깨뜨려 폐기했다.
- `stage_bouncy_04`의 홀을 더 크게 잡는 후보는 기존 두 벽 반사 풀이가 홀에 일찍 포획되어 풀이 계열 증거가 사라져 폐기했다.
- 다중 샷 패턴의 낮은 최종 성공률은 어느 샷이 병목인지 분리하기 전까지 배치 변경 근거로 사용하지 않는다.

## 캠페인 첫 cycle 학습 파형

- 10개 스테이지마다 패턴을 `learn → confirm → apply → mastery` 역할로 명시했다.
- 첫 cycle의 네 번만 역할 순서로 노출하고, 두 번째 cycle부터 기존 결정론 셔플을 그대로 사용한다.
- 기존 first-cycle 중간 저장은 이미 저장된 `remainingPatternIds`를 다시 배열하지 않는다.
- 일일 도전과 탐사 세션은 공용 셔플 정책을 유지한다.
- `drained_03`처럼 쉬운 규칙 확인 패턴은 learn, `balloon_04`·`rotating_reflector_03`처럼 정밀도가 높은 패턴은 mastery에 배치했다.

역할 계획은 현지화된 난도 문자열이나 파일명 순서를 파싱하지 않고 typed `CampaignPatternRole`과 안정 패턴 ID 목록으로 관리한다. 카탈로그와 목록이 다르거나 역할이 빠지면 fresh 캠페인 draw가 명시적으로 실패한다.

## 실패 후 보드 학습 표식

- 현재 결과만으로 사용자의 머릿속 의도를 단정하지 않고 `첫 이탈` 대신 관찰 가능한 `첫 방향 변화`라고 표현한다.
- 재조준을 선택하면 회색 직전 궤적 위에 첫 방향 변화, 첫 충돌, 마지막 충돌을 최대 세 개까지 모양·번호·이중 원으로 표시한다.
- 같은 충돌이 처음이자 마지막이면 하나의 결합 표식으로 줄인다.
- 다음 샷, 되감기, 초기화, 단계 변경, 성공에서는 표식과 의미 요약을 함께 지운다.
- 시스템 뒤로가기도 `바로 다시 조준`과 같은 복원·포커스 경로를 사용한다.
- 저모션 설정에서는 인과 재생을 자동 시작하지 않고 사용자가 재생을 누를 때만 움직인다.

분석기는 빈/직선 경로, 0에 가까운 구간, 범위 밖 충돌 인덱스, 비유한 충돌 좌표, 역순·중복 충돌을 예외 없이 처리한다. 보드 의미 값과 재조준 1회 알림에 같은 짧은 요약을 제공한다.

## 복구 시설 주간 연구 목표

- KST 주간 실험과 같은 `weekKey`를 사용하되 캠페인 목표 스테이지는 전체 10단계에서 안정 해시로 고른다. 잠금 해제나 기록 달성 여부가 변해도 같은 주의 목표가 교체되지 않는다.
- 1·3주차 관측소는 `기믹 완수`, 2주차 등대는 `보정 없이`, 4주차 다리는 `시설 지원 없이` 기록을 제안한다.
- 시설이 아직 복구되지 않았으면 필요한 발견 수, 스테이지가 잠겨 있으면 해금 단계, 조건이 갖춰지면 도전 가능, 이미 기록했으면 기록 달성을 표시한다.
- 주간 실험 완료와 캠페인 개인 기록 달성은 별개다. 물리 실험실 카드에서도 두 상태를 구분해 보여 준다.

### 기록 공정성 수정

- `island_restoration_` 접두사 보유만으로 시설 지원 사용을 판단하지 않는다. 관측소·등대·다리 중 하나의 집중 지원 표식이 현재 런에 있을 때만 사용으로 판정한다.
- 선택 도전 보호가 실패를 자동 보전한 경우 보너스 목표는 유지하지만 `기믹 완수` 개인 기록은 주지 않는다.
- 저장 복구로 완료 처리를 재개할 때도 발사 입력, 보정 종류, 시설 집중 지원, 선택 도전 보호 사용 여부를 같은 규칙으로 평가한다.
- 발사 입력이 비어 있는 비정상 완료는 `보정 없이` 기록을 주지 않는다.

### 화면·회귀 증거

- 320×568, 390×844, 768×1024, 1024×768, 1440×900, 1920×1080 섬 지도 Golden에서 겹침·잘림·오버플로가 없음을 확인했다.
- 320×568에서는 주간 목표를 두 줄 축약형으로 표시하고, 390×844에서는 설명 밀도를 줄여 첫 항해 진행이 초기 뷰 아래에서 계속 이어짐을 확인했다.
- 관련 모델·기록·물리 실험실·복구 효과 테스트 21개와 섬 지도 Golden 6개, `flutter analyze`가 통과했다.
