# 첫 10분 대리 플레이 감사

작성 기준: 2026-08-25 KST

## 판정 범위

초보자, 성급한 모바일 사용자, 퍼즐 숙련자 역할을 분리해 코드·UI·골든·실제 `ShotResolver` 증거를 검토했다. 에이전트는 정답 fixture를 사용자 행동으로 가장하지 않았으며, 이 결과는 실제 사람의 재미·이해도·60초 체감을 증명하지 않는다.

참고 원칙:

- [Apple 게임 온보딩](https://developer.apple.com/app-store/onboarding-for-games/): 한 번에 한 목표를 소개하고 숙련을 확인한 뒤 다음 규칙을 연다.
- [Xbox 난이도 지침](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/108): 정밀 조작 요구와 개별 기믹 보정을 분리한다.
- [Xbox 입력 지침](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/107): 다양한 입력 방식과 실수 복구 경로를 제공한다.
- [Jesper Juul, Fear of Failing](https://jesperjuul.net/text/fearoffailing/): 실패가 다음 전략 변경으로 이어지도록 원인을 읽을 수 있게 한다.

## 발견

1. 핵심 체험 2·3장은 캠페인 5·7단계 패턴을 재사용해 기존 `levelIndex <= 2` 코치 조건에서 빠졌다.
2. 작은 화면의 목표와 상태는 정보 메뉴 안에만 있어 성급한 사용자가 다음 행동을 놓칠 수 있었다.
3. 세 핵심 장면 모두 목표 기믹 없이 홀에 들어가는 생산 fixture가 존재했다.
4. 공이나 기물이 아닌 빈 공간에서 시작한 발사 입력은 설명과 계측 없이 무시됐다.
5. ‘60초’ 완료 시간, 장면별 체류 시간과 중도 이탈을 측정할 공용 세션 연결이 없었다.
6. 생산 40패턴의 기믹 우위 검사는 존재하지만 운영 manifest는 많은 패턴에서 우회 fixture를 성공 증거로 사용해, ‘검증 통과’와 ‘기믹 수행’이 같은 뜻이 아니었다.

## 채택한 수정

- 핵심 체험 장면 번호를 기준으로 속성 원본과 다음 공을 코치 대상으로 지정한다.
- 핵심 체험 중에는 현재 장면 목표를 HUD 아래에 항상 표시한다.
- 물리적으로 홀에 들어가도 장면별 기믹 증거가 없으면 다음 장면 버튼을 잠그고 구체적인 재도전 목표를 표시한다.
  - 장면 1: 무거운 공으로 상자 이동
  - 장면 2: 속성을 잃은 원본 돌 이동
  - 장면 3: 두 번째 샷 이후 과거 공 충돌
- 빈 공간 발사 시작은 한 시도에 한 번 안내하고 `invalid_launch_start`로 기록한다. 속성 물체를 누른 경우에는 잘못된 발사로 세지 않는다.
- 핵심 체험에 앱의 공용 로컬 telemetry를 연결하고 진입·장면 진입·장면 완료·전체 완료·이탈의 경과 시간을 기록한다.

## 검증

- 목표 없는 기존 우회 fixture 세 개는 장면 증거 판정에서 모두 거부된다.
- 생산 대표 기믹 fixture 세 개는 같은 판정에서 모두 통과한다.
- 한국어·영어 핵심 경로 위젯 테스트 15개가 통과했다.
- 수정 파일 정적 분석에서 이슈가 없었다.

실제 사람 테스트 전에는 ‘60초 완료’가 아니라 ‘완료시간과 이탈을 측정할 준비가 됐다’고만 표현한다.
