## 작업 정의

- 작업 ID: `PS-STAGE-02`
- 단계 ID: `stage_drained`
- 패턴 ID: `stage_drained_01`~`stage_drained_04`
- 핵심 학습: 속성을 공으로 옮기면 공만 강해지는 것이 아니라 원본도 속성을 잃어 질량·반발·점착 반응이 달라진다.
- 성공 정책: 속성 이전은 추천 풀이일 뿐 필수 조건이 아니다. 모든 패턴은 `none` 전략의 우회 성공을 허용한다.
- 복사 정책: 기본 복제 코어는 0개다. 보유 중인 복제 코어를 쓰는 선택 경로는 지원하지만 기본 클리어에 필요하지 않다.

## 물리 계약

- `movableWhenDrained`는 속성을 모두 잃었을 때만 원본을 움직일 수 있게 한다.
- 이 설정은 속성이 있는 일반 고체에만 허용한다. 홀·벽·스위치·문·파워 슬라이더·회전 반사판에는 검증 오류를 낸다.
- 일반 돌 질량은 1.6, 무거움 보유 돌 질량은 4.4다. 같은 충돌에서 비워진 돌은 42~46, 무거운 돌은 20~23 논리 단위 이동해 최소 2배 차이를 보인다.
- 탄성을 잃은 젤리는 고유 반사 증폭을 적용하지 않고 일반 이동 고체로 충돌한다.
- 점착을 잃은 원본은 공을 붙잡지 않고 일반 이동 고체로 충돌한다.
- 이동 물체의 운동량 전달은 발사체와 대상의 질량비를 반영한다. 연쇄 이동 중에도 벽·홀·점착·다른 공과의 후속 충돌을 다시 계산한다.
- 벽은 모든 경로에서 고정되며 `movableWhenDrained` 대상이 될 수 없다.

## 상태와 화면 계약

- 속성 선택 팝업은 공이 얻는 능력과 원본이 잃는 능력을 함께 설명한다.
- 옮기기 직후 원본은 `drained` 시각 상태와 실제 원본 스프라이트를 유지하며 회색·저채도 표현으로 비워진 상태를 구분한다.
- 결과 팝업은 4단계에서 5단계 해금을 알리고 `다음` 버튼을 표시한다. 5단계는 현재 마지막 단계이므로 `처음부터 다시`를 표시한다.
- 390×844와 768×1024에서 선택·비워짐·결과 상태 Golden 6장을 확인했다.
- 390×844, 393×852, 430×932, 768×1024, 1024×1366의 5단계 전체 화면 Golden 5장을 확인했다.
- 4단계 해금 문구가 있는 작은 화면에서 순위표와 버튼이 겹치지 않도록 완료 패널 높이를 보정했다.
- 5단계 단일 발사 리플레이 네 개는 `transferSourceId`를 저장하고 재생 전에 실제 속성 이전을 수행한다. 원본의 빈 속성, 이동 가능 상태, `drained` 시각 상태를 확인한 뒤 결과 지문을 비교한다.
- 다섯 단계를 모두 클리어한 기록은 새 저장소 인스턴스에서 안정 ID로 복원되고, 재시작한 섬 지도에서 잠금 안내 없이 모든 단계 카드를 표시한다.

## 프롬프트와 결과 요약

원문 작업 요청은 속성 이전이 공의 강화만이 아니라 원본 약화까지 만드는 5단계를 네 배치로 제작하고, 무거운 돌·탄성 원본·점착 원본·두 원본 선택을 각각 학습시키라는 내용이다. 특정 기믹만 수행해야 성공하는 구조는 금지하며, 복사와 이전의 차이는 보이되 복제 코어를 기본 조건으로 삼지 않는다.

생성 결과는 데이터 기반 5단계 네 패턴, 원본 전용 이동성 스키마, 질량비 기반 운동량 전달, 속성을 잃은 젤리·점착판의 일반 재질 전환, 선택 전후 한글 UI, 지도 해금과 완료 팝업, 대표·대체 해법 fixture, 단일·다중 리플레이, Golden과 검증 도구다. 기존 단계의 탄성·점착 fixture도 실제 보유 속성을 명시하도록 교정해 재질 타입과 속성 효과를 분리했다.
