# PS-STAGE-07: 10단계 속성 한방 데이터·물리 검증

## 범위와 불변 조건

- 안정 단계 ID: `stage_property_shot`
- 제목: `10. 속성 한방`
- 패턴: `stage_property_shot_a`~`stage_property_shot_d`
- 새 기믹과 공통 물리 코드는 추가하거나 수정하지 않았다.
- 모든 패턴은 `copyCharges=0`, `copyCoreReward=0`이며 `none` 직접 우회 계열을 함께 선언한다.
- 벽은 `solid=true`, `movable=false`이고 대표 연쇄 뒤 위치가 변하지 않는다.
- 대표 입력의 힘은 모두 실제 UI 최소값인 12% 이상이다.

## 패턴 계약

| 패턴 | 핵심 기물 구성 | 대표 의도 계열 | 직접 대체 계열 |
| --- | --- | --- | --- |
| A | 무거운 돌, 무거운 상자, 스위치, 문, 벽 | 무거움 이전 → 상자 밀기 → 스위치·문 작동 | 벽 반사 직접 우회 |
| B | 슬라이더, 탄성 물체, 회전판, 돌, 벽 | 슬라이더 → 회전판 회전 → 탄성 충돌 | 직접 우회 |
| C | 점착 원본·일반 받침, 과거 공, 풍선, 상자, 슬라이더, 젤리, 벽 | 점착 준비 → 과거 공 쿠션 → 상자·풍선 연쇄 | 직접 우회 |
| D | 슬라이더, 돌, 내부 벽, 젤리, 과거 공, 외곽 벽 | 슬라이더·돌·벽·과거 공 고연쇄 | 1샷 직접 우회 |

패턴별 핵심 기물 종류 수는 공을 포함해 A 6종, B 6종, C 7종, D 5종이다. 풍선·회전판·슬라이더·과거 공은 기존 엔진의 기물과 실패 공 잔류 규칙을 사용한다.

## 대표 입력

각도는 `360×560` 논리 좌표 기준이며, 힘은 UI 슬라이더 눈금이다.

| 패턴 | 의도 경로 | 직접 우회 | 실제 사건 근거 |
| --- | --- | --- | --- |
| A | `27도/86% → 43도/88%` | `266도/20%` | 속성 공이 `a_crate → a_switch`를 만들고 스위치·문 상태 유지 |
| B | `312도/12% → 203도/70%` | `239도/74%` | 슬라이더로 판 회전, 다음 공이 `b_reflector → b_bumper → 홀` |
| C | `0도/12% → 346도/86%` | `298도/38%` | 첫 공 점착, 과거 공 쿠션, `c_crate → c_balloon` 탄성 연쇄 |
| D | `280도/42% → 312도/84%` | `266도/32%` | 슬라이더, `d_stone`·`d_wall`·`spent_ball_1`, 과거 공 홀 진입 |

A와 C는 각각 `a_stone`, `c_sticky`를 `TraitResolver`로 한 번 이전해 원본을 비운다. 실제 UI처럼 이전된 속성을 첫 `ShotInput.equippedTrait`에도 전달해 `ShotResolver`가 해당 속성 공을 발사하도록 한다. 둘째 발에는 속성을 다시 넣지 않아 한 번 이전 계약을 재현한다. C의 받침은 점착 속성이 없는 일반 고정 벽이며, 같은 첫 입력에서 장착 속성만 빼면 공이 붙지 않는 반례도 확인한다. B는 회전 전 초기 상태에 같은 둘째 샷만 입력하면 `반사판 → 탄성체` 연쇄가 재현되지 않으며, 첫 샷으로 회전한 뒤에만 두 충돌이 순서대로 발생한다.

## 허용 폭과 연결 영역

대표 입력 주변을 실제 `ShotResolver`에 입력했다. 직접 우회는 각도 `±4도`, 힘 `±8%`의 81개 격자를, 의도 연쇄는 첫·둘째 샷 각각 각도 `±3도`, 힘 `±6%`의 49개 입력 조합을 평가했다.

| 패턴 | 직접 성공/최대 연결 | 연쇄 성공/최대 연결 | 연쇄 첫 입력 수/둘째 입력 수 |
| --- | ---: | ---: | ---: |
| A | 56 / 56 | 67 / 25 | 5 / 15 |
| B | 33 / 33 | 210 / 84 | 35 / 6 |
| C | 37 / 37 | 14 / 7 | 7 / 2 |
| D | 58 / 58 | 407 / 156 | 27 / 27 |

성공 여부는 홀 진입과 패턴별 사건 근거를 함께 확인했다. 직접 입력은 성공만 확인하지 않고 각 패턴의 의도 기물 ID와 속성 사건이 충돌·사건 로그에 없음을 검사한다. 네 패턴 모두 의도 기믹을 통과하지 않는 별도 경로가 있으므로 하나의 정답만 강제하지 않는다.

## 잔여 위험

- 섬 지도 10단계 카드·설명·잠금 해제 표시와 게임 화면 목표 문구를 연결했고 390×844·768×1024 지도, 5개 화면 크기 플레이 Golden으로 확인했다.
- 공용 리플레이 fixture는 카탈로그 전체의 기준 패턴 저장·복원 회귀이고, A~D의 핵심 인과 결정론은 전용 동일 초기 상태 반복 테스트가 담당한다.
- 이번 검증은 대표 2계열과 대표 주변 격자까지만 수행했다. 실제 기기 조준 오차, 첫 플레이에서 기물 역할을 알아채는지, 특히 C의 점착·과거 공·상자·풍선 인과 발견성은 수동 플레이테스트가 필요하다.
- 스테이지 추가로 기존보다 전체 자동 검증 시간이 늘었다. 빠른 반복에서는 10단계 전용 테스트를 먼저 실행하고, 커밋 전 724개 전체 회귀를 유지한다.
