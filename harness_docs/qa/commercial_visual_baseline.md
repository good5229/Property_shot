# 상용화 비주얼 QA 기준선

## 현재 관찰

- 배경은 단순 격자와 점 장식 중심이다.
- 벽과 게이트는 단색 직사각형에 가깝다.
- 홀·스위치·점착판은 기능은 구분되지만 같은 세계의 오브젝트처럼 묶이는 아트 규칙이 약하다.
- 상자와 돌은 외부 이미지를 사용하지만 주변 Canvas 오브젝트와 명암·윤곽선 규칙이 완전히 같지는 않다.

## QA 판정 항목

- 첫 화면에서 목표 홀을 2초 안에 찾을 수 있는가
- 공·홀·벽·문·스위치·점착판·젤리·상자·돌의 실루엣이 겹치지 않는가
- 이동 가능한 물체가 히트박스 사각형처럼 보이지 않는가
- 충돌 전후 물체의 위치·크기·그림자가 자연스럽게 연결되는가
- 속성 색상과 무늬가 물체의 실제 기능과 일치하는가
- 390px 폭 화면에서 장식이 조작 대상을 가리지 않는가
- 서로 다른 무료 에셋이 같은 게임의 물체처럼 보이는가

## 심각도

- `CRITICAL`: 목표·장애물·조작 대상 식별 불가
- `MAJOR`: 물체 기능 또는 충돌 원인 오해
- `MINOR`: 형태는 이해되지만 품질이 낮음
- `POLISH`: 색상·그림자·간격·장식 개선
