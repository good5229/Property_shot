# 상용화 비주얼 QA 기준선

## 현재 관찰

- 배경은 장난감 정원 프레임, 필드 격자, 작은 장식으로 계층화되어 있다.
- 벽과 문에는 레일·이음새·경첩·잠금 장치가 있으며, 고정 벽이라는 역할이 화면에서도 드러난다.
- 홀·스위치·점착판·젤리는 목표·조건·재질이 겹치지 않도록 깃발, 점멸, 고정 링, 말랑한 스프라이트로 구분한다.
- 상자와 돌은 프로젝트 자산을 직접 렌더링하고, 이동 중 기울기·구름·압축 변형을 적용한다.
- 홀 포획 시 공은 충돌 지점 이후 홀 중심으로 이동하며 축소·페이드·흡입 링을 재생한다.

자동 검증은 위 렌더 상태의 연결 계약과 충돌 이벤트 시점을 확인한다. 실제 Canvas 픽셀 골든과 실기기 프레임 측정은 아직 별도 검증이 필요하다.

## QA 판정 항목

- 첫 화면에서 목표 홀을 2초 안에 찾을 수 있는가
- 공·홀·벽·문·스위치·점착판·젤리·상자·돌의 실루엣이 겹치지 않는가
- 이동 가능한 물체가 히트박스 사각형처럼 보이지 않는가
- 충돌 전후 물체의 위치·크기·그림자가 자연스럽게 연결되는가
- 속성 색상과 무늬가 물체의 실제 기능과 일치하는가
- 390px 폭 화면에서 장식이 조작 대상을 가리지 않는가
- 서로 다른 무료 에셋이 같은 게임의 물체처럼 보이는가

## 심각도

- `CRITICAL`: 목표·장애물·조작 대상 식별 불가
- `MAJOR`: 물체 기능 또는 충돌 원인 오해
- `MINOR`: 형태는 이해되지만 품질이 낮음
- `POLISH`: 색상·그림자·간격·장식 개선
