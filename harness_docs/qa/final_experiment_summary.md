# 최종 품질 실험 요약

작성 기준: 2026-08-08 KST

상태: 조건부 진행

## 목표

속성 이전·복사, 결정론 물리, 연쇄 충돌, 10단계×4패턴, 오늘의 도전, 런 보상, 리플레이, 한글 모바일 UX와 저장 복구를 하나의 상용 수준 데모 흐름으로 검증한다. 앱스토어 제출 자체는 범위가 아니며, 특정 기믹만 강제하지 않되 기믹 사용 경로가 더 넓고 안정적이도록 설계한다.

## 완료된 범위

- 1~10단계, 단계별 4패턴 총 40개와 결정론적 셔플 백·A/B `RunState` 복구
- 속성 이전·복사, 무거움·탄성·점착·뾰족함, 풍선·젤리·문·스위치·파워 슬라이더·회전 반사판 물리
- 벽 불변, 면 법선 반사, 공·공과 이동 물체 연쇄, 홀 우선 포획, 고속 터널링 방지
- 모든 패턴의 기믹 경로와 무보상 우회 경로 런타임 검증. 우회는 남기되 대표 기믹 경로의 성공 영역을 더 안정적으로 유지
- 전 단계 창의 연쇄 점수, 오늘의 도전 누적 점수·메인 메뉴 복귀·KST 날짜별 저장
- 결정론 보상 8종, 공 꾸미기 즉시 적용, 재도전 중복 지급 방지
- 일반 런·오늘의 도전 리플레이 자동 저장, 최대 24개 A/B 라이브러리, 공유 코드 가져오기와 결과 지문 재검증
- 제품 흐름에 연결된 폐쇄형 텔레메트리 사건 20종과 개인정보 비수집 계약
- 효과음·배경 음악·진동·저모션·화면 흔들림과 실패 인과 표시를 포함한 14개 개별 설정
- 한글 UI, 작은 화면·큰 글자·저모션·주요 화면 Golden 회귀

## 최신 자동 증거

- `flutter analyze`: 오류 0건
- 생산 패턴 40개: 카탈로그 생성본 일치와 제한 런타임 검증 통과
- 전체 테스트 1차에서 최신 홈 기능을 반영하지 않은 Golden 2건을 발견하고 실제 화면 대조 후 갱신
- 영향권 재검증: 홈 Golden 2개와 설정·저모션 Golden 43개 통과
- 최종 전체 테스트: 892개 통과, 실패 0건
- 최신 Flutter Web Release 빌드와 Wasm dry run 통과, 자체 생성 음악 자산의 번들 포함·해시 일치 확인
- 설정 14개 화면과 실제 실패 인과·10단계 런 결과를 390×844·768×1024 Golden으로 추가 검증. 최종 흐름 영향권 86개 통과
- 반복 스트레스: 재도전 20회, 14개 설정 30회 변경, 동일 리플레이 100회, 1~10단계 누적·재개와 A/B 저장 복구 묶음 69개 통과
- Web Release 성능: 390×844·768×1024 발사 p90 17.1ms·17.0ms, p99 모두 17.7ms, 50ms 초과 0건, 콘솔 오류 0건
- 작업별 커밋과 원격 브랜치 푸시 완료

## 남은 위험

- 엄격 p90 16.7ms 목표를 Web에서 0.3~0.4ms 초과
- 실제 iPhone·Android·iPad의 FPS·GPU·메모리·터치·햅틱·Safe Area 미측정
- 초보자 기믹 이해도, 우회 경로 발견률, 만족도에 대한 외부 플레이테스트 없음
- 모바일 배경 음악은 코드·자산·상태 기계까지 연결됐지만 실제 기기 음량·중단·복귀 체감은 미검증
- 슬라이더 터널링·회전 순서·소프트락 이름 fixture는 실제 resolver·발사 가능성 결함 변이로 전환했으며 정상 물리·UI 포함 전체 892개에서 오탐·회귀 없음. 생산 40패턴 전용 CLI 재실행은 도구 사용량 제한 해제 후 필요
- 40개 패턴은 선언된 대표 풀이 계열과 무보상 경로를 검증하지만 모든 가능한 풀이 계열을 완전 탐색하지 않음
- 최종 에셋 권리대장 교차 검토 미완료

## 판정

P0 제품 결함은 현재 자동 검증에서 확인되지 않았고 데모 기능 개발은 계속 진행할 수 있다. 다만 엄격 Web p90, 실기기 성능, 외부 사용성, 모바일 배경 음악 증거가 없으므로 상용 품질 최종 `Go`가 아니라 `Conditional Go`다. 실제 기기·사용자 증거 없이 이 항목을 통과로 바꾸지 않는다.
