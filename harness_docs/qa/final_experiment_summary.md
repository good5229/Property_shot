# 최종 품질 실험 요약

작성 기준: 2026-08-03 KST
상태: 중간 결과 기록

## 실험 목적

속성 이전·복사, 결정론 물리, 다중샷 연쇄, 4단계 퍼즐, 한글 모바일 UX, 저장·해금, 비주얼·타격감이 하나의 제품 흐름으로 작동하는지 검증한다. 앱스토어 출품 자체가 아니라 데모의 품질과 확장 가능성을 판단한다.

- 4개 단계와 지도 해금·클리어 팝업 흐름 구현
- 순수 Dart `ShotResolver`와 렌더링 재생 분리
- 벽 불변성·대상별 충돌·홀 우선·이전 공 연쇄 회귀 추가
- 일반 풍선 반사와 뾰족함 풍선 파괴의 분기 확인
- 진행 저장 버전·구버전 키·손상 값 복구 구조 구현
- 로컬 계측 이벤트를 실제 UI·물리 상태 전이에 연결
- 전체 `flutter test` 237개, 다중샷 물리 분석 1개, 저장 다중샷 재생 1개 통과
- 4단계 각각 성공 2개·실패 2개씩 총 16개 저장 리플레이 픽스처와 결정론 재생 검증 통과
- 4개 단계 × 5개, 총 20개 다중샷 리플레이와 발별 물리 지문 재생 검증 통과
- 네 단계 모두 최소 1개의 실제 2발 상태 전달 시나리오를 포함하도록 픽스처 격자와 회귀 조건 보강
- 개발 전용 튜토리얼 조건군 3종과 조건별 세션 계측 연결, 선택기 회귀 통과
- 개발 전용 진단 메뉴에서 단계 이동·진행 초기화·전체 해금·복제 코어·속성 강제 장착·물리 이벤트·히트박스·법선·프레임 통계를 조정·관찰할 수 있고, Release 번들 비노출을 확인
- 원본 속성 제거·복원, 공 질량·속도·운동량·샷·충돌 식별자, 리플레이 녹화·재생, 사운드·햅틱 토글까지 Debug 메뉴에 연결하고 한글 표시를 확인
- Web Release 빌드 및 다섯 뷰포트 캡처 확인
- 단계4 실제 Web 조작을 390×844에서 재생해 시작·속성 이전·조준·충전·충돌·결과 8장을 확보했고 콘솔 오류 0건을 확인
- 성공 후 `active_ball` 부재로 발생하던 Web 예외를 수정하고 상태 렌더 회귀를 추가
