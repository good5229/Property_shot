# 발사 충전 게이지 검증

## 상태 계약

| 상태 | 진입 기준 | 색상 외 표현 | 손을 뗐을 때 |
| --- | --- | --- | --- |
| 초록 | 힘 0.40 미만 | 얇은 링, 1개 눈금 | 발사 |
| 노랑 | 힘 0.40 이상 | 중간 링, 2개 눈금 | 발사 |
| 빨강 | 힘 0.70 이상 | 굵은 링, 3개 눈금 | 발사 |
| 경고 빨강 | 힘 0.90 이상 | 바깥 경고 링, 완만한 펄스 | 발사 |
| 회색 취소 | 충전 시작 후 1680ms 초과 | 정지 링, X 취소 표시 | 미발사 취소 |

- 충전 활성화 지연 450ms를 포함하면 회색 취소 경계는 pointer down 후 2130ms다.
- 최대 힘 1.0에 도달한 뒤 400ms 동안 경고 빨강 상태에서 정상 발사할 수 있다.
- 한 포인터를 누르는 동안 상태는 뒤로 가지 않고 회색 이후 자동 순환하지 않는다.
- 회색에서 손을 떼면 세션이 끝나며, 다음 새 포인터 입력만 초록에서 다시 시작한다.

## 접근성·저모션

- 화면 읽기 값은 색상과 함께 `약한 힘`, `보통 힘`, `강한 힘`, `과충전 직전`, `발사 취소`를 한글로 알린다.
- 저모션 모드는 경고 링의 펄스와 크기 변화를 제거하고 정적 외곽 링과 명도 차이를 유지한다.
- 회색 진입은 70ms 간격의 이중 햅틱과 실패 피드백을 한 번만 낸다.
- 회색 상태 안내는 발사를 약속하지 않고 `손을 떼고 새로 누르세요`라고 표시한다.

## 검증 근거

- 순수 상태 머신은 각 경계 전후, 상태 역행 방지, 30·60·120Hz 동일 과충전 결과를 검증한다.
- 위젯 회귀는 정상 발사, 과충전 미발사, 회색 안내, 새 포인터 복구를 검증한다.
- 390x844와 768x1024에서 5상태 10장, 저모션 경고·회색 4장의 Golden을 검토했다.
- Golden은 상태별 대표 힘 0.25, 0.55, 0.80, 0.96, 1.0을 사용한다.
- 전체 414개 테스트, `flutter analyze`, 스테이지 생성본 검사, Web Release 빌드가 통과했다.

## 범위 밖

- 파워 슬라이더와 회전 반사판은 각각 PS-OBJ-01, PS-OBJ-02에서 구현한다.
- 스테이지별 게이지 튜토리얼 문구와 난이도 재조정은 신규 기물·5단계 제작 때 함께 검증한다.
