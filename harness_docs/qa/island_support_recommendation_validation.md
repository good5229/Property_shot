# 복구 시설 반복 플레이 추천 검증

검증일: 2026-08-25

## 목표

- 주간 재도전 스테이지의 실제 기믹에 도움이 되는 복구 시설을 추천한다.
- 복구되지 않은 시설은 추천하지 않는다.
- 추천은 설명과 선택 근거만 제공하며 플레이어의 기존 선택을 덮어쓰지 않는다.

## 스테이지별 추천 기준

- 관측소: 상자 이동, 속도 소진, 속성 배수처럼 실패 원인과 충돌 순서 분석이 중요한 단계
- 등대: 탄성, 풍선 연쇄, 가속 구간, 회전 반사판처럼 발사각 오차를 줄이는 조준 보정이 중요한 단계
- 다리: 두 발 해법, 지속 효과, 연쇄 점수처럼 복사 코어가 선택 폭을 늘리는 단계

## 자동 검증

```text
flutter test test/island_restoration_benefit_test.dart --reporter compact
12 tests passed
```

검증 범위:

- 10개 캠페인 스테이지의 기대 시설 매핑과 비어 있지 않은 기믹별 이유
- 복구 시설이 없을 때 추천 미노출
- 선호 시설이 잠겨 있을 때 복구된 시설만 대안 추천
- 잘못된 스테이지 인덱스 거부
- 지도 UI에서 추천 시설과 이유 노출
- 추천 노출 후에도 선택 저장값이 자동 변경되지 않음
- 기존 시설 효과, 집중 지원, 손상 저장값, 작은 화면 스크롤 회귀

## 판정

통과. 복구 시설은 단순 수집 표식이 아니라 이번 주 재도전의 해법 선택을 돕는 기능으로 연결됐으며, 최종 선택권은 플레이어에게 유지된다.
