## 초기 상태 스냅샷


## 저장 기준

현재 진행 저장은 서버 없이 `SharedPreferences`를 사용한다.

| 키 | 의미 | 처리 상태 |
|---|---|---|
| `property_shot_cleared_levels` | 클리어한 단계 인덱스 문자열 목록 | 현재 해금 기준 |
| `property_shot_unlocked_level` | 지도 해금 최고 단계 | 현재 키·구버전 호환 |
| `unlocked_level` | 과거 게임 화면 해금 키 | 읽기·쓰기 호환 |
| `best_shots_level_<index>` | 단계별 최고 샷 수 | 현재 사용 |
| `bonus_goal_level_<index>` | 선택형 추가 도전 달성 | 현재 사용 |
| `property_shot_copy_core_count` | 복제 코어 수량 | 현재 사용 |
| `property_shot_copy_core_rewarded` | 보상 지급 여부 | 현재 사용 |

클리어 목록은 연속된 단계만 지도 해금으로 계산한다. 구버전 최고 해금 값이 있으면 그보다 앞선 단계를 클리어한 것으로 마이그레이션한다. 저장 버전 키와 손상 데이터 복구 정책은 다음 실험 단계에서 추가한다.

## 이벤트 스트림 기준

물리 이벤트는 `ShotImpact`, `ShotAnimationMove`, `PhysicsEvent`로 구성된다. 이벤트에는 대상 ID·타입·충돌 위치·법선·경로 인덱스·충격량·결과 속도가 포함된다. 애니메이션은 물리 이벤트의 순서를 재생하며, 홀 진입은 뒤 벽 충돌보다 우선한다.

현재 자동 검증으로 확인된 범위:

- 벽 고정과 벽 재충돌
- 공·공 충돌 및 이전 공의 홀 진입
- 상자·돌·젤리·점착판·풍선의 타입별 반응
- 스위치 작동과 문 열림 인과
- 30·60·120Hz 이벤트 시간축
- 연쇄 이동의 실제 충돌 이후 시작
