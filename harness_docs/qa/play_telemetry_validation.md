# PS-TELEMETRY-02 플레이 텔레메트리 검증

기준일: 2026-08-08 KST

## 이벤트 계약

- 상위 제품 이벤트는 런 시작, 패턴 추첨, 단계 진입, 속성 팝업·이전·복사, 조준, 충전 단계·취소, 발사, 충돌 연쇄 완료, 보상 제시·선택, 선택 도전, 클리어·재시도·포기, 리플레이 보기, 오늘의 도전 시작, 런 완료의 20종이다.
- 모든 이벤트는 단계·패턴·부호 없는 32비트 시드·resolver 버전·보상 후보와 선택·획득 상태·복제 코어 수·리플레이 여부를 공통 문맥으로 가진다.
- 샷 이벤트는 각도·힘·공 속성·인과 사슬·인과 깊이·유효 연쇄 길이·기물 타입 및 개수·벽/공/기물 활용·점수 감쇠·홀 최근접 거리·프레임 시간·입력 처리 지연·결과를 저장한다.
- 입력 처리 지연은 발사 입력을 확정한 뒤 `ShotResolver` 결과가 생성될 때까지 실제 단조 시간으로 측정한다.
- 이름, 이메일, 전화번호, 주소, 사용자·기기·광고 식별자는 수집하지 않는다.

## 제품 연결

- 일반 런은 첫 패턴 진입에서 `run_started`, 매 추첨에서 `stage_pattern_drawn`, 게임 화면 생성에서 `stage_entered`를 순서대로 기록한다.
- 오늘의 도전은 정식·연습 시작에서 `daily_challenge_started`를 추가하며 일반 진행 저장소와 분리된 문맥을 사용한다.
- 실제 화면 행동 지점에서 속성, 조준·충전, 발사·연쇄 종료, 보상, 선택 도전, 클리어·재시도·포기·런 완료를 기록한다.
- 검증된 리플레이가 재생 화면에 들어갈 때 원문 문서의 단계·패턴·시드·resolver를 사용해 `replay_viewed`를 기록한다.
- 기존 한글 세부 물리 이벤트와 CSV 열 접두부는 호환을 위해 유지한다.

## 자동 검증

- 타입 스키마·직렬화·개인정보 금지·저장 상한·구형 CSV 호환 테스트 통과
- 일반 제품 흐름의 `run_started → stage_pattern_drawn → stage_entered` 순서 테스트 통과
- 성공 샷의 `shot_released → collision_chain_completed → stage_cleared` 순서와 샷 지표 테스트 통과
- 오늘의 도전의 시작 수명주기와 속성 팝업·이전 제품 이벤트 테스트 통과
- 집중 회귀 104개와 전체 정적 분석 통과
