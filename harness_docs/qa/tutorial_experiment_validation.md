# 튜토리얼 조건군 검증

## 구현 범위

최종 실험 계획의 디버그 빌드 조건군 선택을 `TutorialExperimentVariant`로 고정했다.

| 조건군 | 화면 동작 | 내부 코드 |
|---|---|---|
| 안내형 | 대상과 설명 문구를 함께 표시 | `guided` |
| 행동 유도형 | 대상은 표시하고 행동 문구를 짧게 유도 | `action` |
| 무설명형 | 코치마크와 튜토리얼 문구를 표시하지 않음 | `silent` |

개발 실행에서만 홈 화면의 실험 아이콘을 통해 조건을 바꿀 수 있다. Web Release와 모바일 Release에는 선택 UI가 노출되지 않으며, 물리 판정·스테이지 규칙·성공 조건은 조건군에 따라 달라지지 않는다.

## 자동 검증

- `test/tutorial_experiment_test.dart`: 세 조건의 한글 라벨·설명·내부 코드와 개발 선택기 열기·선택 닫기를 검증한다.
- `test/play_telemetry_test.dart`: 세션 시작 이벤트에 조건군 코드를 기록하는지 검증한다.
- `test/widget_test.dart`: 기존 첫 발사·힌트·한글 접근성 회귀를 함께 검증한다.
- `flutter analyze`: 통과.

## 아직 없는 증거

조건군별 초보자 30초 시작률, 1단계 속성 인과 설명률, 재시도율은 실제 참가자 또는 승인된 플레이테스트 로그가 필요하다. 따라서 조건군 구현은 완료했지만 어느 조건이 더 우수한지는 아직 판정하지 않는다.
