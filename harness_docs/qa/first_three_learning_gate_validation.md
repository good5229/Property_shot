# 첫 3스테이지 학습 관문 검증

## 목적

첫 클리어에서 홀만 우연히 통과하는 경로와 핵심 기믹을 실제로 사용한 경로를 구분한다. 한 번 익힌 뒤의 재도전에서는 우회 풀이와 기록 단축을 허용한다.

## 판정 근거

- 1단계: `heavy` 속성을 장착한 발사와 상자의 실제 위치 변화
- 2단계: `bouncy` 속성을 장착한 발사와 반사 이벤트
- 3단계: 스위치 작동 이벤트와 문이 열린 최종 상태

성공 페이즈라도 근거가 부족하면 다음 단계 버튼을 잠그고 보드 안내문을 노출한다. 중단된 성공 상태를 복원할 때도 저장된 발사 결과를 다시 판정하여 빈 기록이 학습 관문을 우회하지 못한다.

## 회귀 증거

`test/first_clear_learning_evidence_test.dart`는 각 단계의 저장된 대표 입력을 실제 `ShotResolver`로 재생한다.

- 알려진 `none` 우회 3개: 물리적 클리어는 성공하지만 학습 근거는 거부
- 대표 기믹 풀이 3개: 물리적 클리어와 학습 근거 모두 승인
- 빈 복원 기록: 예외 없이 보수적으로 거부

조준 허용폭은 각 패턴 회귀의 대표점 주변 15개 입력 테스트와 기본 의도 보정을 유지한다. 이 문서는 자동 에이전트 대리 플레이이며 실제 사용자의 재미나 학습 속도를 증명하지는 않는다.
