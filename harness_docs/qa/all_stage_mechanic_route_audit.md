# 생산 40패턴 기믹·우회 감사

## 발견한 검증 공백

이전 생산 카탈로그 게이트는 실제 `ShotResolver`를 실행했지만, 여러 패턴에서 기믹 풀이 대신 직행·벽 반사 우회 풀이만 대표 증거로 재생했다. 따라서 `runtime validation pass`가 의도된 기믹의 작동을 보장하지 못했다.

## 보강한 계약

- 각 패턴은 의도된 기믹 시나리오를 최소 1개 성공으로 재현해야 한다.
- 속성 이전이 필요한 풀이는 제품 UI와 같이 원본 기물을 선택하고 속성을 이전한 상태에서 재생한다.
- 두 발 이상 풀이는 각 발 직전 상태를 보존해 반사판 회전·슬라이더·과거 공 인과를 발사별로 검증한다.
- 우회 풀이는 의도 기믹 증거로 계산하지 않고, 선언된 대체 해법이 살아 있는지 확인하는 별도 시나리오로 유지한다.
- 누락된 패턴과 우회 시나리오만 있는 manifest는 `missing_intended_mechanic_route_evidence`로 배포를 중단한다.

## 전수 결과

- 생산 10스테이지 × 4패턴: 정규 기믹·대체 해법·무보상 성공·결정론·유한값·벽 불변 계약 통과
- 공–홀 중심선: 40패턴 모두 고체 장애물이 있고, 중심 ±6도·12~100% 범위에서 무의도 직행 클리어 없음
- 900개 각도·파워 표본: 패턴별 기믹 성공 영역이 우회 영역보다 최소 1.40배 이상
- 무기믹 우회율: 패턴별 동일 900개 표본의 10% 이하
- 다발 기믹: 과거 공 6.12배, 연쇄 점수 1.45배, 종합 속성 44.40배의 단계 합산 우위

자동 표본은 물리 회귀와 배포 중단 근거이며, 사람이 느끼는 해법의 자연스러움이나 재미를 증명하지는 않는다.
