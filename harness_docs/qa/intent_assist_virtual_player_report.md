# 입력 보정 가상 플레이어 QA

## 목적

플레이어의 의도와 실제 발사 결과가 어긋나는 정도를 사람 모집 없이 반복 검증한다. 단순 확률 모델이 아니라 제품과 같은 `ShotResolver`와 `IntentAssistResolver`를 사용해 각 발의 충돌·반사·기믹·홀 진입을 끝까지 재생한다.

## 재현 조건

- 생성기: `tool/generate_virtual_player_report.dart`
- 고정 시드: `20260824`
- 표본: 10개 기준 패턴 × 4개 조작 프로필 × 프로필별 80회
- 프로필: 모바일 초보, 일반 PC, 정밀 조작, 키보드·접근성
- 비교: 직접 입력 `OFF`와 정식 도전 기준 `STANDARD`
- 오차 모델: 프로필별 각도·힘 정규분포 오차, 모바일은 작은 포인터와 반복 근접 실패 조건 포함

## 최종 결과

| 프로필 | OFF 클리어 | STANDARD 클리어 | 변화 | STANDARD 기믹 준수 |
|---|---:|---:|---:|---:|
| 모바일 초보 | 30.0% | 35.6% | +5.6%p | 22.3% |
| 일반 PC | 36.9% | 41.4% | +4.5%p | 30.6% |
| 정밀 조작 | 47.1% | 55.1% | +8.0%p | 50.9% |
| 키보드·접근성 | 40.9% | 49.4% | +8.5%p | 42.0% |

- 모든 프로필에서 STANDARD의 전체 클리어율이 상승했다.
- 스테이지·프로필 조합 중 STANDARD가 OFF보다 낮아지는 보정 역효과는 최종 정책에서 0건이다.
- 물리 안전 중단은 OFF 5건, STANDARD 5건으로 동일했다. 모두 5단계의 같은 원시 궤적에서 발생했으며 보정이 새 중단을 만들지 않았다. 충돌 연쇄를 유한 시간에 종료하는 기존 방어 로직이 작동한 결과다.
- 정식 오늘의 도전은 개인 설정과 무관하게 `보통 난이도 + STANDARD`로 고정했다. 연습은 사용자 설정을 유지한다.

## 정책 결정

1. 이미 실제 기물에 닿는 입력은 그 첫 접촉을 플레이어 의도로 간주한다. 양자화가 접촉 대상을 바꾸면 원시 방향과 힘을 보존한다.
2. 3·4·5·7·8단계는 미세한 값이 퍼즐 상태를 만드는 정밀 경로다. 이 단계에서는 목표를 다시 선택하지 않고 원시 궤적과 힘을 보존하며 저속 홀 가장자리 여유만 제공한다.
3. 그 밖의 단계는 아무 기물도 맞히지 못한 근접 실패에 한해 제한된 목표 스냅과 힘 안정화를 사용한다.
4. 정식 기록은 STANDARD로 통일하고, 리플레이·텔레메트리에는 원시 입력과 적용 입력을 모두 남긴다.

## 다음 개선 우선순위

1. 8단계는 보정을 강화하지 말고 대표 연쇄 경로의 각도·힘 성공 영역과 시각적 읽기 단서를 넓힌다.
2. 10단계는 모바일 초보가 첫 두 발의 인과 관계를 이해하도록 발사 전 경로 단서와 첫 실패 후 구체적 조언을 강화한다.
3. 4단계는 풍선을 터뜨려야 하는 이유와 속성 소비 결과를 발사 전부터 보여주고, 기준 패턴의 성공 영역을 넓힌다.
4. 5단계의 체인 안전 중단 입력은 고정 회귀 표본으로 승격해 물리 변경 때 OFF와 STANDARD가 같은 종료 결과를 유지하는지 검사한다.

전체 40개 조합의 원시 수치는 생성기를 실행하면 같은 시드로 다시 출력된다.
