- 실제 모바일 글꼴 rasterizer, 색 재현, 터치 영역은 실기기 체크 항목으로 남는다.

- 섬 지도 카드의 돌·상자·젤리는 실제 게임 최종 스프라이트를 사용하며 공은 공통 `GameBallIconPainter`로 표시한다.
