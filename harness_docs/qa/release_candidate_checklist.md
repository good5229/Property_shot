## 최종 흐름 Golden 증거

- 실패 화면은 실제 1단계 실패 샷의 충돌 순서·마지막 접촉·홀 최근접 정보를 사용한다.
- 런 결과는 실제 10단계 완료, 보상 선택, A/B 저장, 앱 재시작 복원 순서를 거친다.
- 390×844와 768×1024에서 실패 재생·런 결과 4장을 시각 확인했고 관련 회귀 86개와 정적 분석이 통과했다.
- 실제 모바일 글꼴 rasterizer, 색 재현, 터치 영역은 실기기 체크 항목으로 남는다.

## 자산 번들 증거

- 섬 지도 카드의 돌·상자·젤리는 실제 게임 최종 스프라이트를 사용하며 공은 공통 `GameBallIconPainter`로 표시한다.
- Flutter Web Release에는 최종 스프라이트 3개, 자체 음악, 단계 JSON, 선언 글꼴만 포함된다.
- 생성 원본·앱 아이콘 작업 원본·CC0 레거시 PNG·자산 README는 저장소 증거로 남고 Flutter 제품 번들에서는 제외된다.
- 새 번들 계약을 추가한 당시 전체 Flutter 회귀 893개와 정적 분석, Web Release·Wasm 사전검사가 통과했다. 최종 제출 전체 회귀는 상단의 988개 결과를 기준으로 한다.
