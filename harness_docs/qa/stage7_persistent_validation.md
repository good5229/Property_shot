# PS-STAGE-04 7단계 과거 공 재활용 검증

기준일: 2026-08-07 KST

## 구현 범위

- 단계 ID와 제목: `stage_persistent`, `7. 공은 사라지지 않는다`
- 패턴: `stage_persistent_01`~`04`, 기준 패턴은 1번이다.
- 모든 패턴은 의도한 과거 공 활용 경로와 `none` 단일 발사 우회 경로를 함께 가진다.
- 발사된 공은 `spent_ball_N`으로 필드에 남으며 다음 공, 벽, 상자, 점착판, 스위치, 문, 홀과 같은 결정론 물리 계산을 받는다.
- UI는 내부 ID 대신 `첫 번째 공`, `두 번째 공`을 사용하고 속성, 이동 가능, 점착 고정 상태를 표시한다. 과거 공은 속성 옮기기·복사 대상이 아니다.

## 대표 해법과 대체 경로

모든 힘은 실제 UI 최소 힘 12% 이상이며 2% 눈금에 정렬했다.

| 패턴 | 첫 발 | 둘째 발 | 준비샷 인과 | 단일 발사 우회 |
|---|---:|---:|---|---:|
| 1 과거 공 쿠션 | 20도 / 12% | 170도 / 66% | 둘째 공이 과거 공을 움직이고 과거 공이 홀에 들어감 | 0도 / 12% |
| 2 스위치 유지 | 320도 / 12%, 무거움 | 74도 / 100% | 첫 공이 스위치를 누르고 점착판에 고정되어 열린 문 상태를 유지 | 78도 / 96% |
| 3 점착 공 범퍼 | 300도 / 12%, 점착 | 210도 / 12% | 고정된 과거 공에 둘째 공이 반사되어 홀에 들어감 | 2도 / 58% |
| 4 상자 스토퍼 | 130도 / 60% | 260도 / 14% | 첫 공이 상자를 밀고 둘째 충돌이 과거 공의 홀 진입으로 연결 | 50도 / 38% |

같은 둘째 발을 초기 상태에서 바로 실행하면 네 패턴 모두 성공하지 않는다. 따라서 첫 발은 무관한 실패가 아니라 마지막 성공의 준비 상태다. 2번은 첫 발 뒤 `switch_pressed -> sticky_attached`, 스위치 눌림, 문 열림, `stuck`, `movable=false`를 함께 검증한다.

## QA 판정과 남은 위험

독립 QA 첫 감사는 7단계 리플레이의 10% 입력을 P1, 준비 없는 둘째 발 검사와 낡은 체크포인트를 P2로 판정했다. 생성기를 7단계 12% 이상으로 제한하고 리플레이 테스트에 회귀 계약을 추가했으며, 네 대표 경로 모두 준비 없는 둘째 발의 실패를 직접 검사하도록 보강했다.

독립 QA 재감사는 수정된 생성기, 실제 리플레이 JSON, 인과 테스트와 최종 문서를 다시 확인했다. P0·P1·P2는 모두 없으며 최종 판정은 `PASS`다.

자동 검증은 결정론 물리와 화면 배치를 보장하지만 실제 초보자가 과거 공의 역할을 얼마나 빨리 발견하는지는 증명하지 않는다. 7단계의 쿠션, 스위치 유지, 점착 범퍼, 상자 스토퍼 발견률은 후속 사용자 플레이테스트에서 확인한다.
