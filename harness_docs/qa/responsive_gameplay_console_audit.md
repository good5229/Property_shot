# 반응형 게임플레이 콘솔 감사

## 시각 비교에서 발견한 문제

- 모바일·태블릿은 보드와 핵심 기물의 크기가 유지됐다.
- PC·대형 모니터에서는 HUD와 되감기·초기화가 보드 양끝에서 멀어져, 시선과 포인터를 필요 이상으로 이동해야 했다.
- 1024×768 랜드스케이프에서 3단계 튜토리얼 말풍선이 홀의 왼쪽 표현 영역과 접했다.

## 반영한 변경

- 비압축 조작 콘솔의 폭을 화면 높이에 따라 600~840px로 제한했다.
- 보드·HUD·조작부의 수평 중심을 같게 유지하고, 콘솔 모서리와 보드 사이 거리를 양쪽 145px 이하로 제한했다.
- 튜토리얼 말풍선은 보드 폭의 72%, 최대 260px로 조절해 홀 실제 영역과 겹치지 않게 했다.

## 해상도·자산 회귀

- 전체 플레이 화면: 10단계 × 10개 폰·태블릿·PC·대형 모니터 크기 = 100 스냅샷 통과
- 생성 기믹 자산: 10단계 × 4크기 = 40 스냅샷 통과
- 속성 공 자산: 4속성 × 4크기 = 16 스냅샷 통과
- 홈·섬 지도·래스터 자산 기준 화면 통과
- 1024×768, 1024×1366, 1440×900, 1920×1080에서 콘솔 폭·중심·보드 간격 수치 검증 통과

기존 생성 이미지는 고해상도 원본과 `FilterQuality.high`를 이미 유지하고 있어, 이번 작업에서는 외부 자산을 추가하지 않고 레이아웃 응집도와 가림 방지에 집중했다.
