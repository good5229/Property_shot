# 용어 가이드

## 확정 용어

| 사용 | 사용하지 않음 | 이유 |
|---|---|---|
| 무거움 | 무게추, 무게 속성 | 플레이어가 조작 도구로 오해하지 않게 한다. |
| 탄성 | 튕김 속성 | 규칙 이름과 설명을 분리한다. |
| 점착 | 달라붙음 속성 | 짧은 명사형 이름을 유지한다. |
| 뾰족함 | 가시 속성 | 공에 붙는 속성과 source 오브젝트를 구분한다. |
| 속성 옮기기 | 이전 | 출발지·도착지 방향을 명확히 한다. |
| 속성 복사 | 복제 | 원본 유지라는 차이를 직접 드러낸다. |
| 공 | 발사체, 탄환 | 장르와 캐주얼 톤을 유지한다. |
| 홀 | 목표 구멍, 골 | 골프식 목적지를 짧게 부른다. |
| 깃발 | 목표 표시 | 홀의 시각적 표식 이름으로 쓴다. |

## 문장 원칙

- 짧은 한국어 문장과 동작 동사를 우선한다.
- 설명보다 실제 상태와 다음 행동을 먼저 쓴다.
- 영어는 코드·출처·개발 문서에만 남기고 게임 UI에는 노출하지 않는다.
- `정확히`, `반드시`, `완벽하게` 같은 근거 없는 확정 표현을 피한다.
