## 작성 규칙

- 한 화면에서 가장 중요한 행동 하나만 직접 지시한다.
- 물리 결과는 실제로 확인된 경우에만 과거형으로 쓴다.
- 실패를 플레이어의 능력이나 잘못으로 표현하지 않는다.
- `탑뷰`, `회전`, `무게추`, 영어 단축키 표현을 UI에 쓰지 않는다.
