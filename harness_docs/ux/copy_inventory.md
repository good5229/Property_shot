## 공통 작성 규칙

- 한 화면에는 지금 필요한 행동 하나를 먼저 보여 준다.
- 현재 상태, 다음 행동, 행동 결과를 서로 다른 문장·레이어로 나눈다.
- 실패는 관찰된 결과와 다음 시도만 말하고 플레이어를 평가하지 않는다.
- `무게추`, `이전`, `프로퍼티`, `파워`, `Confirm` 같은 표현을 UI에 사용하지 않는다.
- 단계4는 풍선·스위치·문이 실제 화면에서 연결되는 구조와 문구를 일치시킨다.
- 실제 온라인 통계처럼 보이는 기록은 `예시 기록 · 실제 순위 아님`으로 고정한다.
