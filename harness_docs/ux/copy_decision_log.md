# 문구 결정 기록

## 2026-08-03

- `무게추`를 `무거움`으로 교체한다. 사용자가 기능의 의미를 물체 이름으로 오해하지 않도록 한다.
- `이전`을 `속성 옮기기`로 교체한다. 원본에서 공으로 이동하는 동작을 드러낸다.
- 물체 설명을 긴 도움말이 아니라 클릭 팝업의 이름·속성·짧은 설명으로 나눈다.
- 클리어 조건과 선택형 추가 도전을 문구에서 분리한다.
- 실패 문구는 원인 단정 대신 관찰된 결과와 다음 시도 방향을 제시한다.

## 검토 필요

- 실제 사용자 플레이테스트로 첫 단계 문구가 한 번에 이해되는지 확인한다.
- 영어 접근성 레이블이 Flutter 의미 트리에 남는지 검사하고 UI 표시 언어와 분리한다.
- 자동화된 문자열 검사로 금지 용어와 영어 UI 노출을 찾는다.

## 2026-08-03 스테이지4·에이전트 감사 반영

- 풍선 팝 문구를 `풍선이 터졌어요. 뒤의 스위치를 눌러 길을 열어 보세요.`로 바꿨다. 팝과 문 개방을 한 문장으로 합치지 않고, 실제 충돌 순서와 맞춘다.
- 진행 안내를 `풍선 터짐 · 스위치 → 문`, `문 열림 · 열린 길 → 홀`처럼 결과와 다음 행동으로 나눴다.
- 일반 공 안내는 `일반 공은 풍선을 튕겨 냅니다. 밀기와 우회 모두 시도할 수 있어요.`로 바꿔 특정 기믹을 강제하지 않는다.
- 스테이지4 목표는 풍선을 밀거나 터뜨리는 두 경로와 뒤의 스위치 발견을 함께 알리되, 전체 궤적이나 정답 각도는 노출하지 않는다.
- UX Writer 독립 감사에서 확인된 고우선 항목인 장착 후 잘못된 안내, 짧은 화면 문구 잘림, 물체별 접근성 이름, `점착` 용어 통일은 다음 UI 회귀에서 확인한다.
