# 문구 결정 기록

## 2026-08-03

- `무게추`를 `무거움`으로 교체한다. 사용자가 기능의 의미를 물체 이름으로 오해하지 않도록 한다.
- `이전`을 `속성 옮기기`로 교체한다. 원본에서 공으로 이동하는 동작을 드러낸다.
- 물체 설명을 긴 도움말이 아니라 클릭 팝업의 이름·속성·짧은 설명으로 나눈다.
- 클리어 조건과 선택형 추가 도전을 문구에서 분리한다.
- 실패 문구는 원인 단정 대신 관찰된 결과와 다음 시도 방향을 제시한다.

## 검토 필요

- 실제 사용자 플레이테스트로 첫 단계 문구가 한 번에 이해되는지 확인한다.
- 영어 접근성 레이블이 Flutter 의미 트리에 남는지 검사하고 UI 표시 언어와 분리한다.
- 자동화된 문자열 검사로 금지 용어와 영어 UI 노출을 찾는다.
