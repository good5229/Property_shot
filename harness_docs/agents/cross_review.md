# Subagent 교차 검토

- 퍼즐 기획자 ↔ 물리엔진: 선분 샘플링은 레벨 예외 없이 충돌 누락을 줄여 퍼즐 다양성을 보존한다.
- 물리엔진 ↔ 게임 디자이너: 충돌 위치를 샘플 지점으로 바꾸면 충돌 링과 실제 접촉 위치가 가까워진다. 샘플 폭은 4 논리 단위로 제한했다.
- 게임 디자이너 ↔ QA: 새 연출을 추가하지 않고 기존 이벤트를 사용하므로 입력 지연과 상태 불일치 위험이 낮다.
- QA ↔ 전문 플레이어: 최대 힘의 작은 공 시나리오를 자동화했지만 실제 화면의 타격감은 기기 테스트가 필요하다.
- 게임 평가자 ↔ 전 역할: 고속 충돌 보완은 규칙 납득성을 높이지만 실제 재미 점수로 과대 해석하지 않는다.

## 최종 결정

현재 구조를 유지하면서 활성 공 선분 샘플링, 결정론적 후보 정렬, 연쇄 이동 단계 축소를 채택한다. 고정 시간 시뮬레이션 전환은 보류한다.

## 2026-08-01 P0 교차 검토

- 물리 ↔ QA: 연쇄 홀 진입은 사후 경로 검사만으로는 부족하므로, 이동 선분 안에서 벽보다 먼저 종결해야 한다는 데 합의했다.
- 물리 ↔ VFX: `ShotImpact.entityId`를 보존해야 충돌한 대상과 이동한 대상을 분리해 표현할 수 있다.
- VFX ↔ 성능: 문 개방을 반복 펄스에서 짧은 진행률 애니메이션으로 바꾸되, 새로운 파티클이나 외부 엔진은 추가하지 않았다.
- UX ↔ 레벨: 1단계는 보완 가능하지만 2단계는 탄성 차이가 약하고 3단계는 설명 의존도가 높다. 성공 영역 자동 탐색과 실제 플레이테스트를 다음 P0로 둔다.

최종 결정: 이번 반복은 물리 종결·이벤트 식별·팝업 안전성·문 개방 인과관계만 구현했다. 복사 자원 모델과 첫 3단계 전면 재배치는 사용자 결정 또는 실제 플레이테스트 전까지 보류한다.
# 2026-08-02 구현 후 교차 검토

## 공통으로 통과한 항목

- 물리 판정은 순수 Dart에 있고 동일 입력의 결과가 재현된다.
- 벽 고정, 홀 포획 우선, 연쇄 충돌 이벤트 순서, 30·60·120Hz 애니메이션 회귀가 자동 테스트로 확인됐다.
- 복사권 1/1/2, 복사 성공 차감, 되감기 복원, 복사하지 않는 대체 풀이가 확인됐다.
- 320x568·390x844 위젯 레이아웃과 축약 조작 안내가 확인됐다.

## 의견 충돌과 결정

### 충돌: 3단계 기믹 안내를 늘릴 것인가

- 퍼즐·전문 플레이어: 현재 정보량이 많아 실패 뒤 다음 실험을 더 구체화해야 한다.
- 물리·QA: 기믹 우회 경로와 결정론을 유지해야 회귀가 없다.
- 결정: 성공 조건과 물리 판정은 유지하고, 실패 피드백과 온보딩 문장만 개선 대상으로 둔다.

### 충돌: 에셋을 전부 래스터로 바꿀 것인가

- 아트·UX: Canvas 도형과 무료 이미지의 질감 차이가 남아 있다.
- 성능·구현: 현재 Canvas 렌더는 플랫폼 독립적이고 이미지 교체는 메모리 측정이 필요하다.
- 결정: 공통 광원·그림자·외곽선 규칙을 유지하고, 실기기 비용을 측정하기 전 전면 에셋 교체는 보류한다.
