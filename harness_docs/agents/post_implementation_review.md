# 구현 후 교차 재평가

## 공통 판정

세 역할의 독립 재평가 결과는 **조건부 통과**다. 보드 계층, 조준 UI, 직접·연쇄 충돌 `ShotImpact`, 실패 피드백, 한글 접근성, 물리 회귀는 개선됐고 95개 테스트가 통과했다. 그러나 최종 상용 품질로 판정할 증거는 아직 부족하다.

## 역할별 판단

- 아트 디렉터: 목재 프레임과 목표 강조는 개선됐지만 세 단계의 장면 개성과 Canvas·래스터 재질 통일은 부분 충족이다.
- UX·난이도: 실패 이벤트는 늘었지만 초보자의 1~3회 성공률, 성공 각도·파워 폭, 3단계 전체 이해도는 미검증이다.
- VFX·QA: 직접 충돌과 연쇄 충돌을 대상 ID가 있는 `ShotImpact`로 기록·렌더링·재질별 햅틱에 연결했고, 연쇄 이동은 누적 거리로 재생한다. 홀 종결과 문 개방 시간축 회귀도 추가했다. 프레임 지연·실기기 성능은 미검증이다.

## 증명된 항목

- `flutter analyze` 통과
- `flutter test` 95개 통과
- `flutter build web --release` 통과
- 보드·조준·홀·직접 충돌 VFX 변경
- 작업별 commit·push와 최신 서버 HTTP 200

## 남은 P0/P1

1. 애니메이션 종료는 논리 커서 우선·예상시간 Timer 보조로 정리했으며, 백그라운드·프레임 지연에서 실제 시각 흐름을 실기기 검증
2. 재질별 사운드와 홀 흡입·공 축소 VFX
3. 첫 3스테이지 성공 범위와 3단계 전체 시퀀스 자동 검증
4. 실제 iPhone/iPad 입력·프레임·햅틱 측정
5. 사용자의 복사 모델 선택 후 제한 자원 구현

## 중단 없이 남겨 둔 결정

복사 모델은 모델 B(스테이지당 제한 복제권)를 권고했지만, 목표 문서에 따라 사용자 결정 전에는 현재 무제한 복사를 변경하지 않았다.
