# 물리엔진 전문가 독립 진단

## 발견

기존 활성 공 판정은 이동 후 위치에서만 `_firstCollision`을 호출했다. 한 단계 이동 거리가 작은 객체의 유효 반지름보다 크면 시작점과 끝점 모두 충돌하지 않는 터널링이 가능했다. 동일 위치의 복수 후보는 엔티티 리스트 순서에 의존했다.

## 채택안

- 활성 공의 이동 선분을 최대 4 논리 단위 구간으로 나누어 충돌을 검사한다.
- 첫 충돌 샘플 위치를 실제 충돌 위치로 사용한다.
- 동일 샘플에서 복수 후보가 있으면 가장 가까운 경계 후보를 우선하고, 동률은 ID 사전순으로 결정한다.
- 연쇄 이동 단계도 4 단위로 줄여 기존 재충돌 검사를 강화한다.

## 대안 검토

고정 시간 간격 전체 시뮬레이션은 정확하지만 변경 범위와 회귀 위험이 크다. 현재는 선분 샘플링이 비용 대비 적절하다. 이후 고속 터널링이 재현되면 swept collision으로 확장한다.

## 2026-08-01 P0 재진단 및 반영

- 연쇄 이동 공이 홀을 통과한 뒤 홀 뒤 벽에 맞을 수 있는 공백을 확인했다.
- 연쇄 이동 선분에도 홀 진입 시점을 직접 계산하고 `chain_hole_entered` 종결 이벤트로 기록했다.
- 홀 진입 후 부모 연쇄도 즉시 중단해 이후 벽 충돌을 차단했다.
- `ShotImpact`에 `entityId`를 추가해 여러 공·벽 중 실제 충돌 대상을 식별할 수 있게 했다.
- 연쇄 공-홀-벽 회귀 테스트를 추가했다.

## 남은 위험

30·60·120FPS의 실제 렌더 재생, 복잡한 재충돌 루프, 실제 iPhone/iPad 프레임은 아직 미검증이다.
