# 시스템·보상·복사권 감사

## 채택 규칙

모델 A인 스테이지 제한 복제권을 적용했다. 복사권은 1단계 1회, 2단계 1회, 3단계 2회이며, 복사하지 않아도 클리어할 수 있다. 상세 규칙은 [copy_resource_design.md](../design/copy_resource_design.md)에 있다.

## 평가

- 희소성: 무제한 복사보다 전략 선택이 분명하다.
- 이해 가능성: 팝업과 결과 문구에 잔여 횟수를 표시한다.
- 악용 방지: 성공한 복사만 차감하고, 되감기·초기화는 초기 상태로 복원한다.
- 위험: 현재 반복 보상은 최고 시도 기록 중심이라 장기 재도전 동기가 약하다.

실제 사용자에게 복사권이 가치 있는 자원으로 느껴지는지는 미검증이다. 현금 결제나 상점은 추가하지 않는다.
