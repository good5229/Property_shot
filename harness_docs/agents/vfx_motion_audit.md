# VFX·모션·성능·QA 독립 진단

## 핵심 판단

결정론적 물리는 폭넓게 테스트됐지만, 모든 충돌이 동일한 이벤트 구조로 시각·오디오·햅틱에 연결되지는 않는다. 활성 공의 직접 충돌, 홀 포획, 점착 부착, 젤리 충돌은 재질별 차이를 더 분명히 해야 한다.

## 우선 위험

- 물리 충돌과 `ShotAnimationMove`가 1:1로 연결되지 않는 경우가 있다.
- `update(dt)`와 종료 Timer가 애니메이션 종료 기준을 이중으로 갖는다.
- 경로 샘플링은 구간 길이에 따라 화면 속도가 달라질 위험이 있다.
- 매 프레임 블러·그라디언트·이미지 압출·외곽선 렌더링 비용을 실제 iPhone에서 측정하지 않았다.
- 현재 사운드·햅틱은 플랫폼 기본 클릭·알림 수준이며 재질별 차이가 없다.

## 회귀 요구

- 공→벽·돌·상자·젤리·점착판·스위치·홀 직접 충돌 피드백
- 충돌 전 대상 정지와 충돌 후 연쇄 시작 시점
- 충돌 이벤트 순서와 `triggerPathIndex` 순서 일치
- 30·60·120FPS 및 프레임 지연에서 동일한 물리 결과
- Web과 iOS 미지원 햅틱에서 게임 상태 보존

실기기 프로파일링과 실제 사용자 평가는 아직 미검증이다.
