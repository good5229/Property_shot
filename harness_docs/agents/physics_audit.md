# 물리엔진 독립 감사

## 통과 근거

- 순수 Dart `ShotResolver`가 충돌 대상·법선·질량·반발·점착·홀 포획을 결정한다.
- 벽은 고정되고, 닫힌 문은 막으며, 열린 문은 통과한다.
- 연쇄 물체는 실제 충돌 이벤트 이후에만 움직이고, 공·물체·벽의 후속 충돌도 타입별로 판정한다.
- 동일 상태·입력과 엔티티 배열 순서 독립성, 고속 충돌, 홀 선행 포획, 30·60·120Hz 이벤트 중복 방지를 회귀로 검증했다.

## 성능 기준

최신 순수 물리 benchmark 평균은 1단계 330.8µs, 2단계 209.8µs, 3단계 286.7µs다. Canvas·이미지·실기기 프레임 시간은 포함하지 않는다.

## 남은 위험

실제 기기에서 프레임 드롭·GPU 비용·터치 지연과 동시 충돌의 시각적 가독성은 미검증이다.
