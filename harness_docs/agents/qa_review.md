# QA Subagent 독립 진단

## 우선 회귀

- 최대 힘에서 작은 공을 건너뛰지 않는가
- 얇은 스위치·점착판에 진입하는가
- 같은 충돌 위치에서 실행마다 같은 후보를 고르는가
- 기존 벽·점착·젤리·문·홀 테스트가 유지되는가
- 연쇄 객체의 시작 순서가 유지되는가

## 이번 검증

작은 반지름의 남은 공을 활성 공의 이동 선분 중간에 배치한 테스트를 추가했다. `momentum_transfer`가 발생하고, 경로가 중간 위치를 포함하는지 확인한다. 기존 테스트는 삭제하지 않았다.

## 미검증

실제 iOS 입력, 멀티터치, 낮은 프레임 환경, 실제 사용자 튜토리얼 이해도는 미검증이다.

## 2026-08-01 구현 후 재평가

- `ShotImpact` 대상 ID와 연쇄 홀 포획 종결을 검증하는 회귀를 추가했다.
- 커서 기반 종료와 보조 Timer의 팝업 전환을 위젯 테스트로 다시 확인했다.
- 전체 테스트는 95개로 늘었고 `flutter analyze`가 통과했다.
- 자동 테스트는 물리 결과와 위젯 상태를 증명하지만 실제 프레임 시간·햅틱·사용자 이해도는 증명하지 않는다.
