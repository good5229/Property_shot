# 독립 진단 3: 물리·VFX·성능·iOS·QA

## 통과 기반

- 순수 Dart resolver가 최종 판정을 담당한다.
- 벽 고정, 충돌 면 반사, 홀 포획 우선 처리, 충돌 이벤트 전달이 구현되어 있다.
- 순수 물리 샷 계산은 Mac 기준 약 0.32~0.38ms로 관찰되었다.

## 위험

- 상태에 속도·가속도·각운동량이 없어 질량 기반 일반 물리보다 하드코딩된 계수에 가깝다.
- 애니메이션 시간축이 실제 속도보다 경로 인덱스 34에 의존한다.
- 모든 사각형 물체는 AABB이며 회전·투명 영역·정밀 모서리를 반영하지 않는다.
- 전용 사운드와 설정별 음소거·햅틱 제어가 없다.
- Canvas blur·gradient·대형 래스터 디코딩과 매 프레임 재빌드의 실기기 비용은 측정하지 않았다.
- iOS는 Bundle ID 예시값, 서명 팀, 인증서, Simulator Runtime 조건이 남아 있다.
- 최신 팝업 구조 변경 전에는 테스트 파싱 실패가 있었으나 현재 `flutter analyze`와 전체 109개 테스트가 통과했다.

## 우선 QA

- 충돌 이벤트와 화면 이벤트의 일대일 계약 테스트
- 고속 공·동시 충돌·벽 연쇄 회귀
- 320×568부터 1024×1366까지 팝업·Safe Area·한글 오버플로
- 실제 Web release 최신 번들 확인
- iOS verbose 빌드에서 서명과 Simulator Runtime 문제 분리

## 미검증

실제 iPhone/iPad 프레임 시간, GPU·메모리, 터치 지연, 햅틱, 오디오 품질은 아직 확인하지 않았다.
