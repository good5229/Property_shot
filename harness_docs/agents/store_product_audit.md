# 제품·출품 관점 감사

실제 App Store 출품은 이번 범위의 완료 조건으로 주장하지 않는다. 제품 첫인상 관점에서는 목표 홀, 공, 조작 순서가 한 화면에서 보이고, 한글 UI와 귀여운 보드·오브젝트·충돌 피드백이 데모 메시지를 전달한다.

## 남은 제품 위험

- 실기기 캡처가 없어 스크린샷 품질과 작은 화면의 시각 밀도를 최종 판정할 수 없다.
- 실제 사용자 없이 30초 안에 게임 규칙을 이해하는지, 재도전 의향이 생기는지 확인할 수 없다.
- 서버·결제·온라인 랭킹은 구현하지 않으며 로컬 목업 리더보드로 범위를 제한한다.
