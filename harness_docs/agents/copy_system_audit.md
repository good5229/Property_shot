# 속성 복사 시스템 독립 진단

## 현재 상태

현재 복사는 원본 물체의 속성을 유지한 채 공에 같은 속성을 추가하며, 횟수 제한이 없다. 튜토리얼 학습에는 쉽지만 이전과 복사의 차이가 전략적으로 느껴지지 않는다.

## 모델 비교

### 모델 D: 현재 무제한 복사

- 장점: 가장 쉽고 구현 비용이 낮다.
- 단점: 복사 선택의 긴장감과 희소성이 없다.
- 판단: 학습용 임시 상태로 유지하되 최종 모델로 확정하지 않는다.

### 모델 A: 스테이지당 제한 복제권

- 1단계 1회, 2단계 1회, 3단계 2회처럼 단계별로 제공한다.
- 되감기·단계 초기화에서는 횟수를 복원한다.
- 장점: 초보자에게 설명하기 쉽고, 레벨 설계 통제가 쉽다.
- 위험: 잔여 횟수를 항상 보여주지 않으면 불공정하게 느껴질 수 있다.

### 모델 C: 세션 공유 소프트 재화

- 장점: 장기 반복 플레이와 연결할 수 있다.
- 단점: 현재 세 단계 수직 프로토타입에는 메타 시스템이 과하고, 핵심 물리보다 재화 관리가 앞설 수 있다.

### 모델 B: 물체별 1회 복사

- 장점: 복사와 이전의 차이가 가장 선명하다.
- 단점: 물체 사용 상태와 되감기 복원이 복잡하다.
- 판단: 모델 B 검증 후 확장 후보로 둔다.

## 권고안

모델 A를 권고한다. 복사 버튼에 `복사 1회 남음` 같은 한글 잔여 상태를 표시하고, 소진 시 비활성화한다. 기본 튜토리얼은 이전만으로 풀리게 유지한다. 3단계에서 복사가 필요한 경우에는 최초 진입 시 제한 수량을 명시한다.

## 사용자 결정 전 보류

- GameState에 복사 횟수 필드 추가
- SharedPreferences 저장 키 추가
- 복사 버튼의 소모 규칙 변경
- 레벨별 복제권 수량 확정

사용자 결정 전에는 현재 복사 동작과 테스트를 보존한다. 단, 이전과 복사의 결과 차이를 명확히 보여주는 한글 UI 문구는 먼저 개선할 수 있다.
