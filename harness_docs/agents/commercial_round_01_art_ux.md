# 독립 진단 1: 아트·UX·제품

## 판정

현재는 모바일 라우팅이 추가된 중간 단계이며 임시 점수는 54/100이다. 홈·지도·플레이 연결은 개선됐지만 상용 품질 게이트에는 미달한다.

## 핵심 근거

- 홈은 물·모래 해변인데 플레이 보드는 민트색 잔디와 타일 그리드로 분리되어 있다.
- 상자·돌·젤리는 래스터 품질이 높지만 벽·문·스위치·점착판은 평면 Canvas 도형이다.
- 벽은 회색 산업용 레일처럼 보이고, 홈 공과 플레이 공의 표현이 다르다.
- 실제 플레이 모드의 단계 칩은 숨겨졌고 보드는 화면 폭을 활용한다.
- HUD와 하단 패널은 여전히 개발용 설명이 많고, 지도는 경로형 섬보다 목록에 가깝다.
- 결과 팝업에 기록·별·보너스가 들어오며 좁은 화면 경계가 회귀했으나, 이후 고정 행동 영역 구조로 수정하고 109개 테스트가 통과했다.

## P0

1. 플레이 보드를 해변 실험 섬으로 통일한다.
2. 벽·문·스위치·점착판을 상자·돌·젤리의 공통 광원·접지 규칙으로 재작성한다.
3. 긴 설명과 개발용 하단 패널을 맥락형 코치 마크로 줄인다.
4. 홈 공과 플레이 공의 브랜드 이미지를 통일한다.

## P1

- 섬 지도를 실제 경로와 잠금 상태로 변경한다.
- 스테이지 3 대표 이미지는 문·스위치 연쇄를 보여준다.
- 390×844, 393×852, 430×932, 768×1024 스크린샷을 새로 만든다.

## 미검증

실제 사용자 플레이, 실기기 성능, 스토어 첫인상은 아직 검증하지 않았다.
