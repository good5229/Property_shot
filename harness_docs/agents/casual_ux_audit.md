# 캐주얼 UX·난이도 독립 진단

## 핵심 판단

현재 테스트는 성공 가능한 입력이 존재하는지를 증명하지만, 초보자가 1~3회 안에 성공하는지와 실패 원인을 이해하는지는 증명하지 않는다.

## 단계별 위험

- 1단계는 물체 선택, 속성 이전, 조준, 롱프레스, 파워, 상자 밀기, 홀 조건을 한 번에 학습시킨다.
- 2단계는 직접 홀을 노리는 단계가 아니라 첫 충돌면을 노리는 단계라는 안내가 더 필요하다.
- 3단계는 점착 공이 단순 조건인지 다음 샷의 발판인지 설명이 부족하다.

## 채택한 개선

- 조준 화살표와 파워 링의 색상 역할을 분리했다.
- 낮은 힘·높은 힘 실패 이벤트를 추가해 다음 시도에서 바꿀 행동을 알려 준다.
- 대표 1단계의 시선 흐름은 `무거운 돌 → 공 → 상자 → 홀`로 유지한다.

## 다음 테스트

- 방향 1도·파워 1% 단위의 성공 범위 계산
- 첫 3회 내 성공 가능한 대표 입력 고정
- 상자·스위치·젤리·홀 가장자리 입력 회귀
- 실제 사용자가 첫 행동과 실패 원인을 설명하는지 확인

실제 사용자 테스트 전에는 직관성이 검증됐다고 주장하지 않는다.

## 2026-08-01 독립 재진단

- 1단계는 무거운 돌이 공의 진행 흐름에서 멀어 속성 선택 이유가 시각적으로 약하다.
- 2단계는 일반 공도 벽 반사를 하므로 탄성의 차이가 충분히 드러나지 않는다.
- 3단계는 점착·무거움·스위치·문·홀을 동시에 요구해 첫 3단계의 마지막 학습 단계로는 복잡하다.
- 1도·0.02 파워 연속 성공 영역, 첫 3회 성공률, 첫 실패 후 변경 행동은 아직 검증되지 않았다.

권고: 다음 레벨 반복에서 먼저 성공 영역을 자동 측정하고, 그 결과를 바탕으로 대표 1단계의 조준 허용도와 2·3단계의 안내 순서를 조정한다. 실제 사용자 없이 직관성 통과 판정은 금지한다.
