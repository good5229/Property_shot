# 퍼즐 난이도 독립 감사

## 현재 판단

- 1·2단계는 자동 탐색에서 넓은 성공 입력 영역과 대체 경로를 확인했다.
- 3단계는 점착 발판, 무거운 공의 스위치 경로, 기믹 없는 직접 경로를 모두 허용한다.
- 특정 기믹을 성공의 필수 조건으로 만들지 않는 사용자 원칙을 유지한다.

## 남은 문제

- 3단계는 기믹이 많아 초보자가 무엇을 먼저 관찰해야 하는지 모호할 수 있다.
- 실패 팝업은 재시도 행동은 제공하지만 마지막 충돌 순서와 다음 실험을 충분히 구체화하지 않는다.
- 자동 성공 영역은 실제 사용자의 이해도와 동일하지 않다.
