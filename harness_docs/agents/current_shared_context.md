## 비협상 규칙

1. 벽은 어떤 연쇄에서도 움직이지 않는다.
2. 충돌한 대상의 실제 타입·질량·법선·재질에 따라 후속 계산한다.
3. 뾰족함은 풍선에만 특수 작용하며 1회 사용 후 소모한다.
4. 풍선은 일반 공에 터지지 않으며, 팝 상태는 즉시 충돌 후보에서 제외한다.
5. 신규 기믹을 수행하지 않아도 독립적인 성공 경로를 남긴다.
6. UI에 영어 표현을 노출하지 않는다.
7. 작업별로 테스트·문서·commit·push를 남긴다.

## 에이전트 리뷰 요약

- Epicurus: 기존 3단계 보존을 위해 신규 기믹을 4단계 독립 슬라이스로 추가하고, 뾰족함 없이도 우회 경로를 남기라고 권고했다.
- Hooke: 충돌·연쇄·분석·Flutter 회귀를 다음 QA에서 확인해야 하며, 속성 분기와 이전 공 연쇄를 별도로 검증해야 한다.
- Newton: 풍선은 산호색 타원·매듭·끈, 뾰족함은 가시 성게 실루엣으로 설계하고 Canvas와 래스터 광원 규칙을 맞추라고 권고했다.
- Lorentz: 충격량은 법선 상대속도·질량·재질을 사용하고, 팝·문 열림 이벤트를 애니메이션 순서에 포함해야 한다고 지적했다.
