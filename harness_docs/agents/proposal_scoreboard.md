# 자율 개선 제안 평가표

점수는 목표 약속, 초보자 이해, 보편성, 시각·조작 품질, 접근성, 효과, 회귀 위험, 테스트 가능성을 각 0~5점으로 평가한다. 총점 32점 이상, 보편성·테스트 가능성 4점 이상인 제안만 채택 후보로 삼았다.

| ID | 제안 | 총점 | 판정 | 실제 반영·근거 |
|---|---|---:|---|---|
| P-01 | 상황 기반 코치 마크와 짧은 목표 | 38 | 채택 | 첫 단계·스테이지4 안내, `game_screen.dart` |
| P-02 | 결과 화면의 다음 스테이지 우선·즉시 재도전 | 36 | 채택 | 클리어 팝업 위젯 회귀 |
| P-03 | 선택형 실패 힌트와 원인·다음 행동 분리 | 35 | 채택 | UX 문구 인벤토리·실패 메시지 |
| P-04 | 조준 중 최종 궤적 표시 | 18 | 거절 | 도전성과 정보 과다 위험, 비협상 원칙 위반 |
| P-05 | 풍선 팝을 유일한 클리어 조건으로 강제 | 14 | 거절 | 대체 풀이 원칙 위반 |

제안은 최대 5개로 제한했고, 채택된 기능은 독립 테스트 또는 Golden 증거를 가진다. 실제 사용자 효과는 플레이테스트 전에는 확정하지 않는다.
