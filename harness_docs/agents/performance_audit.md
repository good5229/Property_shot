# 성능 감사

## 순수 물리 기준선

`dart run tool/physics_benchmark.dart`로 각 레벨을 1,000회씩 같은 입력 집합에 실행했다. 이 측정은 Canvas 렌더링, 이미지 디코딩, 실제 기기 프레임 시간을 포함하지 않고 `ShotResolver` 계산 비용만 측정한다.

| 단계 | 총 시간 | 1회 평균 | 확인값 |
|---|---:|---:|---:|
| 무거움 익히기 | 312ms | 312.6µs | 75521 |
| 탄성 익히기 | 215ms | 215.2µs | 48110 |
| 연쇄 문 열기 | 280ms | 280.3µs | 63726 |

## 판정

- 세 단계 모두 현재 데모의 단일 발사 계산을 반복 실행할 수 있는 순수 Dart 비용으로 확인했다.
- 확인값은 벤치마크 루프가 최적화로 제거되지 않았는지 확인하기 위한 결정론적 누적값이다.
- 이 결과만으로 30·60·120FPS 실기기 안정성을 보장하지 않는다.

## 남은 검증

- 실제 iPhone·iPad에서 Canvas 프레임 시간
- 이미지 메모리와 파티클 비용
- 저사양 기기에서 연쇄 애니메이션 프레임 저하
- Web과 iOS의 입력 지연 차이
