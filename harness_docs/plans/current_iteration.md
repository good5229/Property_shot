# 현재 반복 계획

## 채택

- 활성 공 이동 선분 샘플링으로 고속 터널링 완화
- 충돌 후보별 선분 최초 시점 정제와 동률 ID 기반 결정론 정렬
- 연쇄 이동 단계를 4 논리 단위로 축소
- 작은 공 고속 충돌 회귀 테스트 추가
- 물체 탭 정보 팝업 우선 흐름과 팝업 안의 속성 옮기기·복사
- 클리어 팝업 지연을 주 발사 경로와 연쇄 이동량에 연동
- 이동 물체의 전체 애니메이션 경로를 홀 판정에 사용
- 세로 화면 고정과 3라운드 배경 수직 슬라이스 장식 보강
- 무게 스위치의 속성 조건과 거절 피드백
- 작은 화면 팝업 스크롤, HUD 말줄임 제거, 롱프레스 취소, 로컬 기록 로딩 보호

## 보류

- 전체 고정 시간 물리 시뮬레이션 전환
- 외부 물리엔진 도입
- 신규 속성·레벨·온라인 기능

## 이번 반복의 QA 판정

기능 QA는 통과했다. `flutter analyze`, `flutter test` 101개, 320x568 위젯 검사, `flutter build web`, 데모 HTTP 200을 확인했다. 3단계 점착·스위치 없는 경로도 자동 탐색으로 실제 홀 진입까지 감사했다.

- 데스크톱 HUD에 조준 방향과 0.45초 롱프레스 자동 발사 안내를 추가했다.
- 젤리 표시 폭을 물리 히트박스 비율에 맞춰 보정했다.
- 3단계에서 특정 기믹 없이 홀에 도달하는 대체 경로를 자동 탐색 회귀로 고정했다.
- 전체 테스트 101개와 `flutter analyze`가 통과했다.
- 모바일 첫 단계 메시지에 자동 발사 순서를 명시하고 390x844 캡처로 말줄임 없음을 확인했다.
- 3단계 우회 탐색에서 기믹 없는 경로와 무거운 공의 스위치·문 경로라는 두 해법 계열을 확인했다. 우회 방향 폭은 실제 사용자 조정 대상으로 남긴다.

## 복사권 모델 B 적용

- 첫 챕터 시작 시 복사 UI를 숨기고 복사 없이 클리어 가능한 구조를 유지한다.
- 3단계 클리어 보상으로 `복제 코어`를 획득한 뒤에만 속성 팝업에서 복사가 가능하다.
- 복제 코어를 사용하면 1개 차감하고, 되감기·단계 초기화에서는 해당 시점의 수량으로 복원한다.
- 복사하지 않는 대체 풀이와 클리어 판정은 유지한다.
- 1·2단계 성공 입력은 연결된 영역 기준으로 각각 각도 16도·16도, 파워 0.86·0.72, 최대 격자 성분 248셀·223셀을 확보했다.
- 3단계는 점착 없이 무거운 공을 `(1, -1.3)`, 힘 1로 발사해 스위치·상자 연쇄·반사 후 홀에 진입하는 대체 경로를 고정했다.

다음 반복에서는 연쇄 재충돌 루프, 30·60·120FPS 프레임 재생, 첫 3단계 추천 풀이와 대체 경로의 사용자 이해도 검증을 우선한다.

출품 QA는 아직 미완료다. iOS 서명·프로비저닝, 에셋별 라이선스 원문과 상업 이용 증빙, 실제 iPhone/iPad 입력·프레임 테스트, 1~3라운드 추천 풀이와 대체 경로의 사용자 검증, 30/60/120FPS 충돌 시간축 검증, 앱 아이콘과 전체 오브젝트 아트 통일이 남아 있다. 2026-08-02 재검증에서도 Xcode 16.2의 iOS 18.2 Simulator Runtime이 없어 `flutter build ios --simulator` destination 단계에서 중단됐다.
