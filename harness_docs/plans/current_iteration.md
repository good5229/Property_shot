# 현재 반복 계획

## 채택

- 활성 공 이동 선분 샘플링으로 고속 터널링 완화
- 충돌 후보별 선분 최초 시점 정제와 동률 ID 기반 결정론 정렬
- 연쇄 이동 단계를 4 논리 단위로 축소
- 작은 공 고속 충돌 회귀 테스트 추가
- 물체 탭 정보 팝업 우선 흐름과 팝업 안의 속성 옮기기·복사
- 클리어 팝업 지연을 주 발사 경로와 연쇄 이동량에 연동
- 이동 물체의 전체 애니메이션 경로를 홀 판정에 사용
- 세로 화면 고정과 3라운드 배경 수직 슬라이스 장식 보강
- 무게 스위치의 속성 조건과 거절 피드백
- 작은 화면 팝업 스크롤, HUD 말줄임 제거, 롱프레스 취소, 로컬 기록 로딩 보호

## 보류

- 전체 고정 시간 물리 시뮬레이션 전환
- 외부 물리엔진 도입
- 신규 속성·레벨·온라인 기능
