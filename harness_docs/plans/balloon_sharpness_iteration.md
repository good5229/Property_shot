# 풍선·뾰족함 반복 계획

1. 도메인·속성·풍선 상태와 4단계 수직 슬라이스를 추가한다.
2. 일반 충돌·뾰족함 팝·이전 공 연쇄·되감기 테스트를 고정한다.
3. 충격량 지표를 VFX·진동·팝 이벤트에 연결한다.
4. 3단계 기본 분석과 4단계 고해상도 전략 분석을 분리한다.
5. 390×844, 393×852, 430×932, 768×1024, 1024×1366 캡처와 콘솔 오류를 확인한다.
6. 결과에 따라 풍선 위치·충돌 여유·우회 경로를 조정하고 작업별로 commit/push한다.

현재 완료: 1~3의 기본 구현, 신규 단위 테스트, 지도 4단계 노드, 역할별 리뷰 문서.
남은 검증: 4단계 고해상도 성공 영역, 서버 최신 캡처, 성능·iOS 증거.
