# 사용자 결정 필요 항목

## 속성 복사 희소성 모델

### 현재 문제

현재 복사는 무제한이다. 규칙 학습에는 쉽지만, 속성 이전과 복사의 전략적 차이가 약하고 복사 선택의 긴장감이 없다.

### 선택지 A: 스테이지당 제한 복제권 (권고)

- 단계마다 1~2회 제공
- 리셋·되감기 시 복원
- 장점: 구현과 설명이 쉽고 초반 난이도를 통제하기 좋음
- 단점: 잔여 횟수 표시가 필요함

### 선택지 B: 물체별 1회 복사

- 각 속성 물체에서 한 번만 복사
- 장점: 이전과 복사의 차이가 가장 명확함
- 단점: 상태 저장과 되감기 규칙이 복잡함

### 선택지 C: 세션 공유 재화

- 스테이지 보상으로 얻은 재화를 복사에 사용
- 장점: 반복 플레이 동기 제공
- 단점: 현재 수직 프로토타입 범위를 크게 넓힘

### 선택지 D: 현재 무제한 유지

- 장점: 학습과 접근성이 가장 쉬움
- 단점: 전략성과 희소성이 부족함

### Subagent 의견

- UX·난이도: 초반에는 모델 A 또는 B가 적합하고, 최종 권고는 B
- 퍼즐 설계: 모델 B가 레벨별 선택을 통제하기 쉬움
- 시스템 설계: 모델 C는 후속 메타게임으로 보류
- QA: 모델 B 도입 시 소모·복원·비활성 상태 테스트가 필요

### 권고안

모델 A인 스테이지당 제한 복제권을 채택한다. 1단계 1회, 2단계 1회, 3단계 2회를 초기안으로 제안한다.

### 답변 전까지 중단되는 작업

- 복사 횟수 저장·소모 규칙 구현
- 복사 버튼의 최종 UI 변경
- 복사에 의존하는 레벨 규칙 변경
